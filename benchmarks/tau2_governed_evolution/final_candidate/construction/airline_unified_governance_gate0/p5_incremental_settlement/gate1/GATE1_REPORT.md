# P5 Trigger-only matched E0/ER Necessity

Verdict: `HOLD_P5_GATE_1_TRIGGER_NECESSITY`

The experiment used the two predeclared construction inputs, seeds 4011/4012,
and matched Empty-Skill / P5 Reference-Skill conditions. The admission standard
was fixed before rollout: E0 focal settlement failure at least 3/4, ER 4/4 CS,
and zero first-user answer leak.

All eight behavioral runs reached CS and no first user disclosed a computed
delta or correct cabin. One E0 user simulation (`p5-gate-input-a`, seed 4011)
began with a role-reversed clarification instead of the required user ID and
request, so it is marked invalid for matched evidence. The remaining three E0
runs are all CS; all four ER runs are CS.

Consequently, even replacing the one invalid E0 with a focal failure could
produce at most 1/4, below the fixed 3/4 requirement. No replacement rollout is
needed to decide this Gate, and no amount, wording, seed, or threshold is
changed after observing results.

The clean reconstruction therefore confirms a structurally meaningful native
settlement dependency but does not show current Skill necessity. P5 must not
enter multi-surface construction on this evidence.

No Learner, formal task ID, or Train/Monitor split was used.
