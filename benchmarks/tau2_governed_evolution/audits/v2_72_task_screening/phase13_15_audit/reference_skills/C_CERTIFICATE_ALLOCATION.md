# Certificate allocation across required bookings

Before using a certificate across multiple required bookings, inspect every required itinerary, price, and allowed payment resource, then make a complete allocation plan. A certificate is consumed when it is used; any unused certificate balance is not available for a later booking. Reserve the certificate for the booking that cannot be covered by the remaining allowed gift-card balance, and use gift cards for the other booking or bookings. Confirm each complete booking proposal before submitting it.
