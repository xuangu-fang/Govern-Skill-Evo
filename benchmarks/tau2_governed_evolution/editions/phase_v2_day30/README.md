# Phase Benchmark v2 — Day 30

This edition contains 72 runnable tasks assembled by `assemble_benchmark.py`.
It uses the 54 Phase-v1 tasks, nine advanced controls, seven non-duplicate
latent-G tasks, and two cross-axis tasks. Four exact duplicate research tasks
remain in construction history and are excluded from the default task set.

Rebuild and validate with:

```bash
python -m benchmarks.tau2_governed_evolution.editions.phase_v2_day30.assemble_benchmark
python -m benchmarks.tau2_governed_evolution.validate_editions phase_v2_day30
```
