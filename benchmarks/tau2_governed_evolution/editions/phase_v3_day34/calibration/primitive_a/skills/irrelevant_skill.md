# CALIBRATION ONLY — Irrelevant Procedural Skill

## Post-action communication check

- After completing a requested operation, compare the user-facing response with
  the request and state only the outcome that was actually observed.
- Mention unresolved parts explicitly and avoid claiming success for operations
  that did not complete.
- Keep the final response concise, distinguish confirmed facts from assumptions,
  and do not add unrelated recommendations.

This matched-quality control does not teach state refresh, identifier renewal,
or downstream target resolution. It must not enter Parent Skill, Diagnosis,
Editor, evolution memory, task metadata, or Learner-visible input.
