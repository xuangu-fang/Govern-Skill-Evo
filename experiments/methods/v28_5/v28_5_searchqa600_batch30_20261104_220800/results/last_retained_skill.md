# Question Answering Skill

- Determine the answer type requested by the interrogative phrase after 'this' or 'these' before selecting a span from the passages; if the question asks for a place, territory, state, or country, return that place itself rather than a university, institution, organization, region, or other adjacent entity named in the same passage, unless the question explicitly asks for that adjacent entity. When both the requested place and an institution named after it appear, make the requested place the final answer element.
- When a question asks for a source or set of animals or materials and the passages distinguish a primary or especially characteristic source from secondary or occasional alternatives, return the primary/characteristic item or items in the answer element; treat wording such as 'especially' or 'particularly' as a signal for the characteristic answer, and do not append rare or exhaustive alternatives unless the question explicitly asks for all possibilities.
- When the question asks for a phenomenon or class and the passages present it as a singular headword or definition, use that singular established term in the answer element rather than a plural inflection used in examples, unless the passages' direct answer label or title is itself plural or the clue explicitly asks for multiple separate items; preserve such plural forms and do not convert a plural count noun that names the requested set into a singular.
- For a person, return the conventional name form that directly identifies the requested individual in the passages and completes the clue. If the person's name appears in more than one given-name or name-length variant, use the form found in a passage title or section heading that directly names that person in preference to a variant found only in running text. When several such title/heading forms name the same person, prefer the form that includes a given name or nickname with the family name over a bare-surname form; use the bare surname only when no title/heading supplies a given-name or nickname-plus-family form, the clue and passages uniquely identify the individual, and the bare form is the direct label. Do not append given names from running text to a bare-surname heading form.
- If no title or section heading directly names the person, use the passage's direct answer label or its established complete personal-name form (given name or nickname plus family name) as the shortest conventional complete form, rather than reducing to a bare surname merely because that surname is unique in the passages. In all cases, do not repeat a family or house label already supplied by the clue when that label is not the requested specific name; include an honorific or title only when it is part of the passage's direct named form and the clue supplies no part of the person's name; do not append separate descriptive phrases. If complete name forms remain ambiguous among passage people, or the passages identify the person only by a fuller form, use the fuller personal name given by the passages.
- For an organization, when the passages provide both an expanded full name and an established shorter form (including an abbreviation), use the shorter established form alone in the final answer element when the passages use it to identify the organization, including when it appears as part of the name of the specific entity asked about; do not pair the full name with the shorter form or return both forms.
- If the passages do not establish a shorter form, use the organization's ordinary full name.
- When the supplied passages reproduce the question or a near-verbatim version of the clue and include an explicit answer label for that clue, use the label's wording in the final answer element, even when it is a bare surname or otherwise shorter than a fuller name found in a title or running text. Apply this only when the label identifies the entity requested by the clue and no conflicting label for the same clue appears; this rule overrides conflicting name-form preferences in this Skill when such a label exists, and otherwise the existing title/heading and complete-personal-name preferences continue to apply, including their preference not to reduce to a bare surname.
- When the clue already supplies the category noun or relationship for the requested item, make the final answer element the specific term that completes it; do not repeat the clue's category word or add a descriptive relationship phrase, even when a passage's direct answer label is a compound of that category word and a specific modifier. Return the specific modifier alone when it unambiguously identifies the requested item. For a bare list of two or more names with no explicit interrogative, return the shared place, office, party, or other common affiliation alone rather than a sentence describing the relationship. Preserve the full term when the category word is integral to an established proper name or when dropping it would make the answer ambiguous. This boundary rule controls over the explicit-label rule above when a compound label repeats a clue category word or descriptive relationship phrase.
