# Question Answering Skill

- When a question asks for 'this type/kind/variety' of something, answer with the specific named subtype that the context associates with the clue's identifying feature; do not substitute the broad class or a general/temporal modifier plus that class. When the clue instead says 'the [modifier] type of this' or 'the [modifier] version of this', treat the modifier as clue-supplied and answer the underlying base category or object, omitting the modifier unless the full modified phrase is itself the requested established proper name.
- When a clue gives a functional definition (what an item is applied to or used for) or a named process step, and the passages contain both a direct class/product term or the substance explicitly placed at that step and separate examples or alternative substances, answer the direct class/product or step-specific substance; do not substitute a specific home-remedy example or an alternative chemical from a broader or different process. Preserve a more specific answer only when the clue asks for an example, brand, or subtype.
- When the question asks for a title, term, role, or other named label—including when it lists a work's characters or identifying details—put that requested label itself in the answer element; do not return a descriptive clause, plot summary, or a title embedded in an explanatory sentence.
- When the supplied passages give a work title or name in an unaccented spelling (for example, 'Les Miserables'), answer with that unaccented spelling and do not add diacritics that the passages do not use; when both an unaccented and an accented form appear, use the unaccented form present in the passages unless the question explicitly asks for the accented form. If the passages give the name only in an accented form, keep that accented form rather than stripping its diacritics.
- When two or more candidate people, products, or works appear in the passages, select the single candidate whose passage satisfies every explicit clue constraint (role, office, place, date, action, or visual description); do not choose a candidate merely because a distinctive phrase from the clue occurs near its name or because it is a familiar candidate. For a 'seen here' clue where no image is available, choose the item whose passage directly combines the clue's brand or category with the stated action rather than a different item that merely shares the brand.
- If the clue names an example after 'like' or 'similar to', identify the role or category that the example illustrates rather than returning the example. When a clue uses a plural demonstrative ('these') or a brand example after 'like' to refer to a class of beverage, material, or other mass/type category, answer with the conventional singular category term used in the passages rather than pluralizing it or substituting one example. Preserve a plural form when the clue and context define a count-noun group as plural rather than a mass/style category.
- If the clue defines a generic phenomenon and the context also gives a named event or instance containing the term, return the generic term, not the named event. When the clue describes a general category, translated term, or shape comparison, answer the basic common-noun meaning or general object named in the context; do not expand it into a proper heraldic name or a narrower species or modified-object variant unless the clue explicitly asks for that subtype or the narrower phrase is necessary to identify the referent. Preserve a conventional subtype when the question asks for that subtype and the context gives it as a fixed expression.
- In a 'this is the term for ...' or similar singular definition clue, match the grammatical number of the defined term as the context states it in its singular definition rather than copying a plural class label used for examples; return the singular noun when the clue asks for one term. Preserve an inherently plural conventional answer only when the context and clue request a plural group.
- For a single selected entity, term, group, category item, or work, answer with one complete answer unit: do not enumerate alternatives, occasional examples, source-qualified options, or a parenthetical expansion. When the context gives a usual or primary item plus merely occasional alternatives, answer the primary item. Answer with the conventional name that identifies the requested referent, not the entire supporting phrase: when the clue already supplies a generic category or role and the context gives a conventional name containing that same category or modifier, return the name without merely repeating the clue-supplied descriptor—use the bare distinguishing noun for a descriptive phrase, and use a short established range or trade name when the context makes that shorter conventional name clear. When the clue asks for a person's nickname or moniker after already naming the person, return the nickname label alone rather than the nickname plus that surname. Do not narrow a requested general category to a subtype or modifier the clue does not ask for: if the clue asks for one of a general class, answer that class term as the context names it, not a fuller subtype. Drop a category word or modifier already supplied by the clue, descriptive words from an organization title or supporting phrase when they are not needed to identify the specific answer, a trailing generic category noun that merely repeats the clue's category (for example a house, party, network, desert, or company/legal suffix) or a separable terminal company suffix/designator, and a colon-separated translation or subtitle that is not part of the usual work title when the clue asks for the usual work title. When the passages use a base work title as the complete usual designation and also give a longer form with a colon-separated subtitle or descriptive continuation, answer the base title and omit that added subtitle or continuation unless the clue explicitly asks for the full title or subtitle. Do not omit a colon-linked part that the passages establish as inseparable from the work's usual title; keep a leading article or other fixed wording that belongs to that usual title, and keep words needed to distinguish the work when the base title alone would be ambiguous. Also drop a separable brand/franchise prefix when the context also uses the bare work title, and a property word already encoded by the clue's translated name; when the clue asks for 'the rate/number/amount of this', answer the measured object rather than the full compound containing that relational noun. Preserve the fuller title or name when an extra word is an inseparable part of the fixed proper title or conventional subtype or is needed to distinguish the referent, and keep a category noun when it is part of the established name; do not preserve a mere industry/class descriptor that the clue already supplies when the distinguishing name alone identifies the entity. Keep a distinguishing modifier, role, or subtype that the clue explicitly requests or that is needed to distinguish the referent, and keep a publication-type word when the clue asks for the name of a periodical and the context establishes that word as part of its title.
- When a clue is a declarative statement or proverb with a possessive/anaphoric pronoun ('his', 'her', 'its') pointing to an unnamed person or thing, return that referent's name; do not answer yes/no or merely confirm the statement. Preserve the conventional name/title that identifies the referent and omit explanation.
- When the context identifies the requested person with a personal honorific such as 'Sir' placed directly before the full name (for example, 'Sir Isaac Newton'), include that honorific with the full name in the answer unless the clue explicitly asks only for a surname or given name. Do not add a military rank, office, or occupational title such as General, President, or Senator as a name prefix, and do not add an honorific that the context does not attach to the person or that is not needed to identify the referent.
- For an individual geographic feature whose context-established name includes a designator such as Lake, River, Mount, or Sea, keep that designator as part of the answer even when the clue lists sibling features without it or itself supplies the category word (for example, 'this river'); the designator belongs to the established proper name, so this keeps a category noun that is part of the name and takes precedence over the general instruction to drop a category noun already supplied by the clue. Do not reduce an established name to the bare distinguishing word, and do not add a designator or descriptive category word that the context does not present as part of the feature's name or merely because the broader category uses it.
- When a no-predicate clue is only a comma/ampersand-separated list of names, resolve what the listed entries share before answering. If all listed entries are character names or character-role labels from a single fictional work, return that work or series; do not return the work's setting, an actor, a team, event, or other incidental association merely because a passage repeats the listed names. If the entries are place names, return their shared country, or the corresponding nationality/category that connects them when the context supports that form. For other titled or personal-name lists, answer with the single shared geographic or political jurisdiction (country, state, or principality) that the context associates with the listed entries, preferring the shared state/country over a family, party, or role relationship; do not return a title or role phrase, a family relationship, party affiliation, a descriptive gloss, an expanded address or place description, or multiple alternatives. For a single titled personal name or bare place name, answer with the single country/jurisdiction that the context associates with it. If no shared work or jurisdiction relation is established, return the single entity or named person the clue most directly denotes rather than inventing one.
- When the question is a terse fill-in cue ending in a bare abbreviation/code after a colon, is only a quoted fragment with an ellipsis, or contains an explicit fill-in frame such as a prefix followed by 'this' or a quoted phrase ending in a demonstrative ('this/these'), answer what the abbreviation denotes, the missing word/phrase that completes the fragment, or only the word/phrase that fills that slot; do not return the cue itself or the whole compound word, repeat the clue-supplied portion, or substitute a related landmark, title, or phrase. If the clue separately asks for a named work/title rather than a missing word part, preserve its full conventional title rather than truncating it.
- When a clue's wordplay explicitly describes one word being changed into another by removing or replacing a letter and the context supplies both the source word and the changed word together as the answer, return that joined pair in the form the context uses rather than only the changed word. Likewise, when wordplay resolves to both forms of a slash-joined homophone pair that the context supplies as the answer, treat that joined pair as one requested answer form rather than as separate alternatives, and return the pair in the joined form the context uses (for example, 'be/bee') instead of only one spelling. Do not extend either rule to ordinary alternate spellings or names for a single term (for example, 'Filo/phyllo'), where the answer remains the single established term; continue to return a single established term when the context does not present a wordplay pair.
- When a bare clue is a speaker-labeled dramatic or fictional dialogue quotation (a character or speaker label followed by quoted speech or an ellipsis) and does not explicitly request an author, missing word, or other named item, answer with the work title that the passages identify for that quotation rather than the author. When a clue is only an unlabeled complete line of poetry or a literary quotation with no explicit request for a title, author, or missing word, return the named author of that quotation from the context rather than the poem's title. When a clue is only a quoted catchphrase, slogan, or exclamation with no explicit fill-in blank or request for a named referent, use the context's attribution: if the context attributes the phrase to a named person it promotes or identifies—as with a campaign slogan or a sportscaster's catchphrase—return that person, not a descriptive clause naming the event, year, office, or running mate, and not the song or work whose title merely contains the phrase. If the context presents the phrase only as a work or franchise name and not as promoting a named person, return the work or franchise conventionally associated with the phrase, not a later spin-off or installment whose title merely contains it; if the clue separately asks for a named person, object, missing word, title, or author, answer that requested item instead. Reserve that catchphrase-specific work-title behavior for catchphrases, slogans, and quoted titles that the context presents as a work or franchise name.
- When a clue asks for 'this site/place/landmark' and mentions a building, tower, church, or other feature located there, return the containing site/place/landmark itself, not the named building or feature; use the larger location as the answer when the clue's demonstrative refers to it. Preserve a building name only when the clue explicitly asks for the building rather than the site. Likewise, when a bare, non-interrogative clue describes a place by a notable feature or resource it contains ('home to ...', 'that contains ...') and does not explicitly ask for a named building, site, or landmark, answer the containing state, country, or continent that the context associates with it, not the local named forest/grove, habitat type, or material; keep a local feature name only when the clue's demonstrative explicitly refers to that feature or the clue asks for the feature itself.
