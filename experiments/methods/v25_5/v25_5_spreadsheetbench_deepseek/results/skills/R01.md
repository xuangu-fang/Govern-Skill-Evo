# Spreadsheet Manipulation Skill (xlsx)

## Overview
This skill guides agents in manipulating Excel (.xlsx) spreadsheets using Python.

**Primary libraries**: `openpyxl` (structure-preserving read/write), `pandas` (data transformation).
Never use any other third-party libraries.

---

## Common Workflow

1. **Explore** the input file: list sheets, inspect headers, check dimensions.
2. **Write `solution.py`** with `INPUT_PATH` and `OUTPUT_PATH` defined at the top.
3. **Execute** `python solution.py` and verify the output file was created.
4. **Confirm** the target cells/range contain the expected values.

---

## Calculated and Formula Targets

For calculated ranges or formula deliverables, derive each result from the source rows/blocks named by the instruction or from the contiguous source table whose headers match the destination labels; resolve destination row/column labels, control selectors, and criteria from actual cell values instead of assuming coordinates from an example formula. Compute each designated readable result independently from the source data, preserving the expected type (number, text, date) and allowing a legitimate blank result. If the task requires formulas, write the formula at the intended writable cells and ensure the saved cached result matches the independently computed value; if it requires values, write the computed values. Writing to those intended cells supersedes any prior value or cached result there. After `wb.save()`, reopen the output with `openpyxl.load_workbook(OUTPUT_PATH, data_only=True)` and compare each designated cell's readable result and required formula presence with the independently computed/expected result. If a label or control is blank or unrelated, a target cell is unexpectedly unwritten, or a cached value is missing or inconsistent, search for the correct label/range or use the explicit answer region and fix the source selection, formula, or cache. After fixing, save and recheck the final saved output; if the same check still fails, raise an execution error naming the cell and the expected and observed behavior rather than submitting a silent heuristic guess.

## Library Selection

| Use case | Library |
|----------|---------|
| Preserve formulas, formatting, named ranges | `openpyxl` |
| Bulk data transformation, aggregation, sorting | `pandas` → write back with `openpyxl` |
| Simple cell read/write | `openpyxl` |

**Warning**: `pandas.to_excel()` silently destroys existing formulas and named ranges.
When writing back to a spreadsheet that contains formulas, always use `openpyxl.save()`.

## solution.py Template

```python
import openpyxl
import pandas as pd

INPUT_PATH  = "..."   # set to the actual input path
OUTPUT_PATH = "..."   # set to the actual output path

wb = openpyxl.load_workbook(INPUT_PATH)
ws = wb.active  # or wb["SheetName"]

# --- perform manipulation ---

wb.save(OUTPUT_PATH)
```

## Output Requirements

- Save the result to `OUTPUT_PATH`.
- Do not hardcode row counts or column letters — iterate over actual rows in the workbook.
- Preserve sheets and cells not mentioned in the instruction.
