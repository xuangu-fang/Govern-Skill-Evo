# ALFRED Task Execution

## Locating a target

- When the target is not found at first, search deterministically: sweep forward through location names or numbers, or through receptacle classes, instead of cycling among the same few locations.
- After checking a location and observing that the target is absent, including after opening a container whose visible contents lack the target, prefer an unchecked admissible location over returning to a previously checked one.
- Expand across genuinely different receptacle and surface types, including outlying or non-kitchen receptacles when present, before revisiting checked sites.
- At minimum, avoid choosing a location that appears in the immediately preceding observations or actions when another admissible unexamined location exists, unless a new observation indicates the target may now be there.

## Clean-and-place tasks

Follow dependency order:

1. Locate and acquire the requested target object. Verify that it matches the request; do not substitute an unrelated object.
2. If the target's source container is closed, open it before taking the object.
3. Go to the appropriate cleaning fixture, such as a sinkbasin when available, and clean the held target.
4. Go to the requested destination. If the destination container is closed, open it before placing.
5. Move or place the cleaned target into or onto the destination.

## Admissible actions

- Only select actions that appear in the current admissible action list.
- If an intended location or action is absent, do not issue it and expect progress. Instead, choose an available alternative, such as another listed location or a currently available examine or open action, and continue the plan from there.
