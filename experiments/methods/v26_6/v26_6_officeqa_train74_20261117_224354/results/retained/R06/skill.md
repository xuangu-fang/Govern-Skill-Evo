# OfficeQA Skill

## Retrieval Discipline
- Start by narrowing to the most likely candidate file before reading long passages.
- Prefer targeted search terms that name the exact entity, period, measure, or table concept from the question.
- After a promising match, read only a small surrounding span and verify it matches the requested year, basis, and unit.

## Evidence Discipline
- Before doing any arithmetic, copy each operand literally from the retrieved row, or from the initial parsed page when that is the available document text, and verify that the exact digit string appears in the source. Do not substitute a remembered, rounded, or reconstructed number. If a tool attempt returns a path-not-allowed error or a recursive filename search returns no matches, use one flat filename glob to recover the allowed document locator, then read or search the exact row and compare the digits before arithmetic. Apply this check when the same row label appears in more than one table or year. If only the initial parsed page is available, still copy the exact characters from that page and compute only from those characters.
- Keep track of each operand's period, unit, and semantic role so nearby proxy values are not mixed in.
- When a calculation uses multiple periods and the same period appears in both an earlier bulletin table and a later bulletin table, check the later table for an explicit revision marker on any period included in the calculation. If the later table marks that period's value as revised, substitute the revised value before computing instead of the earlier unrevised value. Use the complete earlier table for periods without a later revised value, and use the later revised values for the periods they cover. Apply this only when the later table visibly ties the revised value to the same measure and period; do not substitute a merely similar label or a different measure.
- If the question asks for a transformed or derived quantity, compute only after confirming every operand.
- When one question asks for a share or percentage for named months or years and also asks for a correlation or another statistic derived from the same table, bind every component to the named period first. Compute the correlation over the same named monthly or period subset; do not expand to adjacent months or fiscal-year totals merely because they appear in the retrieved table. A reference to the table or to a named series, such as a 'grand total series,' does not by itself specify a broader period than the months or years the question names. Use a broader series only when the question states additional periods or an explicit date range for the correlation.
- When building a combined subtotal from a table block introduced by a category heading, include only the rows whose labels identify the holdings or securities named in the question. Exclude adjacent rows for different account types, such as receivables or payables, unless the question explicitly names them or asks for the entire block. Before dividing the subtotal by a table total, state the included row labels and confirm that each one belongs to the requested category; if a row is ambiguous between a component and a separate account, leave it out. Use the table's stated total as the denominator when the question asks for a share of that total.

## Final Answer Discipline
- Return the final answer only after one last consistency check against the retrieved evidence.
- Copy the final answer from a checked value, not from an unverified intermediate guess.
- Inside the `<answer>` element, return only the requested answer value. For a numeric result, give the number alone in the unit the question already specifies; do not append unit words, labels, explanatory prose, or parenthetical alternative conversions inside the tags. Distinguish a question that names a percent quantity from one that states how the answer is to be reported. If the question asks for a percent or percent change and only says to round to a given decimal place, return the bare numeric value inside the tags and do not append a percent sign, except when the question asks for a percentage loss or otherwise instructs that the sign be part of the reported answer. Include a percent sign only when the question explicitly requires the answer in percentage terms, asks for a percentage loss, or otherwise instructs that the sign be part of the reported answer. Continue to return a bare number for percentage-point changes, for a decimal number of percentage points, and for values in thousands or millions, and keep the requested rounding. These reporting choices apply after the calculation. A short explanation or consistency check may appear before the final answer tag if useful, but not inside it. The final-answer response does not request another tool.
