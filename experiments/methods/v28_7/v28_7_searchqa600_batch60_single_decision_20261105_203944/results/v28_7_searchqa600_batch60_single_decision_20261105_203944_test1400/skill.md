# Question Answering Skill

- As an exception to the exact-label/headword rule for office or role titles: when the clue itself already identifies the country and the passages give both a country-qualified formal office title and a conventional shorter office title, answer with the shorter office title without the redundant country qualifier, provided that title remains unambiguous. Keep the office-defining words and any honorific that is part of the conventional name; use the country-qualified title only when the clue asks for the formal title or the shorter form would be ambiguous.
- When a clue is a descriptive location phrase ('Home to...' or 'That contains...') that does not explicitly ask for a named local feature, and the passages supply both a local named feature (such as a grove, forest, or material body) and a containing state or continent associated with the described fact, answer the containing state or continent rather than the local feature; if the clue explicitly asks for the local feature by name or type, return that requested feature.
- When the question consists only of one or more personal names or honorific titles and does not explicitly ask for a role, office, title, or relationship, and the context identifies the named person or persons as rulers of a country (including two rulers of the same country), answer with that country alone. Do not substitute the ruler's title/role or an explanatory sentence about the relationship; if the question explicitly asks for the person or office, answer that requested entity instead.
- When the question consists only of a quoted catchphrase that the context associates with a broader series or work, and the context also contains a later installment derived from that work, answer with the broader originating series/work rather than the derivative installment title. Return the work name alone, without adding a description of the installment. Do not apply this when the question asks for the derivative installment by name or asks for a description of it.
- When the clue is only a quoted signature catchphrase or call, and the passages explicitly identify a named person as the one who says it, answer with that named person rather than the sport, event, organization, or program the phrase introduces; if the clue explicitly asks for that event, sport, or program, return the requested entity instead.
- When the clue explicitly marks the requested answer with 'this'—for example, an incomplete quoted line ending in '... and' this or a relative clause such as 'X does this, which they grow on ...'—answer the missing word or the object described by that relative clause, not the title of the surrounding work or a nearby material noun; if 'this' instead refers to a title, place, or other named entity, return that named entity.
- When the clue is only a campaign slogan pairing a nickname with another person (for example, a '… and … too' form) and the passages explain that it belongs to a presidential ticket, answer with the principal candidate denoted by the nickname rather than the running mate or a song, album, or other work that merely contains or is titled by the slogan; if the clue explicitly asks for the running mate, the work, or the other named person, return that requested entity instead.
- When a clue is a declarative statement about an unnamed person or thing (for example, a possessive phrase such as "his 1983 album" or a factual statement ending in an identification), answer the unnamed person or thing that satisfies the clue rather than returning "True" or "False"; answer true/false only when the question explicitly asks whether a statement is true or false.
- When the question asks for a generic term, type, or category (such as "the term for...", "these", "a series on these", or "these birds/animals") and the context contains both that generic term and a proper-named instance or title, answer with the generic category term rather than the named instance, unless the question explicitly asks for the proper name. When the question asks for a generic term, type, or category and the passages contain both a broad category noun and a narrower compound subtype for the same referent (for example, "trains" versus "passenger trains", or "balloon" versus "speech balloon"), answer with the broad category noun alone rather than the subtype; use the subtype only when the question explicitly asks for that narrower kind.
- When the clue is a definitional description beginning with an indefinite category ('An/A [category] ...') or otherwise defines a type by its function rather than asking for an example, answer the generic term or headword that matches the whole definition; do not return a specific substance or product mentioned in the passages merely as an example, and keep the grammatical number requested by the clue.
- When a passage provides the requested answer term or name itself as a terse answer label or as the dictionary/encyclopedia headword (rather than merely as part of a longer proper name or title), use that supplied form exactly, including its grammatical number, except that when the clue asks for "the term" for a class of things using a singular demonstrative or singular category (for example, "this is the term" or "one of these"), return the singular count noun even if the supporting passage's label or definition uses a plural form; when the clue uses a plural demonstrative such as "these" to refer to examples of an uncountable category and the passage supplies that category as a singular mass noun, return the singular mass noun rather than pluralizing it; do not pluralize the term or copy a plural sentence fragment merely because the passage uses it. Keep the supplied form's grammatical number when the requested category is a count noun, the clue itself requests multiple discrete items or plural members, or the referent is inherently plural. Do not otherwise pluralize or singularize it, and do not replace it with a longer name or description from another passage. Exception: when the clue itself supplies the answer's category or type (for example, a company, a structure, or a set of mountains) and the passage's answer form is longer only because it repeats that category/type word or adds a descriptive modifier from the clue, omit the repeated word or modifier and return the shortest distinguishing proper name or head noun; do not repeat the clue's category word or add a description. When the passages supply an organization's or entity's multi-part proper name, preserve all genuine proper-name components, including both parts of an "&" name even when the clue already shows one; do not reduce it to the unshown partner alone. However, when the clue itself calls the requested entity a company or organization and the passage gives a formal name of the form "<distinguishing name> Company" or "<distinguishing name> Organization", treat that Company/Organization suffix as the clue-supplied generic category rather than a multi-part proper-name component, return the distinguishing name alone, and retain internal punctuation, hyphenation, and all genuine proper-name components; do not omit the suffix when the clue asks for the full legal/formal name or when the category word is part of an established common name rather than a separable clue category. Do not append or retain a separate generic category word that the clue itself supplies merely as the requested category (for example, do not add "Mint" to "Denver" or "Mountains" to "Adirondacks"), including an institution's formal category word when the clue asks for that institution by its category and that word is merely the clue's generic category; however, retain an ordinary common-name category word that is part of the established term rather than a separable clue category (for example, keep "tree" in "eucalyptus tree"). For a lake or river, when the passages give a conventional full name in which a feature word such as "Lake" or "River" is part of that name, return that full conventional name and keep the feature word even if the clue lists sibling features without the word or uses the plural category (for example, "the Great Lakes" or "this river"); do not extend this exception to a generic category word that the clue supplies merely as the requested category and that is not part of the established name, so the existing rule that omits such a word still applies, and if the passages give only the distinguishing name without the feature word, do not invent the feature word. For other entities, prefer the shortest established proper name, subject to preserving multi-part proper names and established common-name category words. This exception also covers a category or location word when the question itself uses that same noun, allowing grammatical inflection (for example, "this market", "this vitamin", or "this state university at Superior"); do not treat a looser synonym as the same category. Except for an ordinary common-name category word that is part of the established term as described above, do not repeat that noun even if the passage's label or headword includes it; return the distinguishing term or base name alone (such as "bear" for "bear market", "C" for "vitamin C", or "University of Wisconsin" for the campus at Superior), while retaining any proper-name component needed to identify the requested entity. When the question calls a publication a "journal," keep a supplied "magazine" category word, but when the question calls a political group a "party," a supplied distinctive nickname may be returned without appending "Party." The exact-label rule applies unchanged to all other questions.
- When the clue gives a year and an incomplete quoted title with an ellipsis replacing its beginning or another component, answer only the missing title component needed to complete the quoted fragment rather than the full title supplied by the passages; return the full work title only when the clue asks for the work as a whole.
- As an exception to the exact-label rule, when a work's heading gives a main title followed by a colon and a subtitle or descriptive phrase, and the question asks for the work itself without requesting the subtitle or full title, answer with the main title alone and do not append the colon-separated portion; preserve the title's own articles and meaningful components. Use the colon-separated portion only when the clue itself uses it, asks for it, or it is needed to distinguish the work, including when the heading's pre-colon title is non-English and the post-colon portion is an English translated title or subtitle. Ordinary headings without a colon-separated subtitle remain governed by the exact-label rule.
- For a person answer, when no terse answer label is supplied, use the name form given by the relevant passage heading that names the person rather than expanding to a fuller formal name from another passage, except that when the clue itself supplies the person's given name (for example, a clue asking for the only president named Chester), answer with the surname alone rather than a heading form that repeats the given name. If a heading gives a familiar full name, use that familiar full name instead of substituting the formal given name; if the heading gives only a surname, use the surname; if the heading gives the fuller conventional name, keep that form. Continue using these heading-form rules when the clue does not supply the given name. When a person's name includes initials, use the spacing given by the relevant passage heading or terse answer label: keep consecutive initials unspaced when that source presents them unspaced (for example, 'W.C. Fields') and spaced when it presents them spaced, preserving the initials' punctuation even if body text elsewhere uses the other spacing; this refines only the spacing of the existing person-name rules. Omit rank and role or job titles unless the clue asks for them, but keep an honorific such as 'Sir' when the heading or passage presents it as part of the person's conventional name.
- When a clue asks for a site, place, state, country, or other encompassing location and mentions a named building, district, or subdivision within it, answer the encompassing location asked for, not the subordinate building or division; use the subordinate name only when the clue asks specifically for that building or division. When the question is only a place name or a short phrase naming places and does not explicitly request a city, state, building, or other specific entity, identify the encompassing country from the passages: return the country name for a bare city-name clue, and return the country's adjectival demonym when the clue is phrased as "In [place] & [place]" rather than as a descriptive phrase about the city. If the clue explicitly asks for a city, state, or other specific place, preserve that requested granularity.
- When the question is only the name of a park or protected area that explicitly contains 'State' (for example, a 'State Park' name) or the passages describe it as a state park, answer with the U.S. state associated with that place alone rather than the country; do not apply the bare-city-name-to-country default to this named state-level place. If the clue explicitly asks for the country, or the place is not identified as state-level, keep the requested or broader containing location.
- As an exception to the exact-label rule, when the question consists only of a company's name and does not explicitly ask for the company, a product, a model, or other entity detail, and the passages identify the country associated with that company, answer with the country alone rather than the formal corporate name or a product/model name. Return the entity itself when the clue asks for the company or other entity detail. Do not extend this exception to a clue that names a specific product or model rather than the company.
