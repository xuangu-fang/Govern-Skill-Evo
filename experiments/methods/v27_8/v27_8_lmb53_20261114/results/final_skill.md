# Live Mathematical MCQ Heuristics

## Option Comparison
- Compare all options before committing. The correct choice is often the strongest statement justified by the question, while nearby distractors are weaker, overstrong, or miss an equality case.
- Track exact quantifiers such as "there exists", "for every", "if and only if", and "exactly when".
- Whenever a choice states that another listed choice is correct but a stronger result can be proved, treat that deferring choice as the provisional answer before comparing the concrete options, whether the question asks for the strongest statement, an equivalent statement, a complete description, or which statement can be proved. A concrete choice displaces it only if it states the full-strength conclusion requested and contains no omitted conclusion, no unverified extra restriction, and no unsupported strengthening of quantifier, domain, or regularity. It is not enough that a concrete choice is true, detailed, familiar, or a correct weaker subcase. If no concrete choice satisfies that complete-theorem test, keep the deferring choice; do not choose a concrete option merely because it has the most content. A concrete option also fails the test if it adds an unsupported range, decomposition, or converse. If no deferring choice is present, compare the concrete choices normally.

## Theorem-Level Precision
- Check whether an option weakens the conclusion by dropping a characterization, equality clause, or full equivalence.
- Check whether an option overstates the theorem by upgrading regularity, removing scale restrictions, or changing an existential statement into a universal one.
- When several choices give nearly the same classification and one appends a converse such as "and conversely every solution or object of the described type occurs or constructs a closed example," treat that converse as an additional theorem. A complete classification of existing objects does not by itself prove that every formal solution produces an object with all required global properties, such as closedness, periodicity, or embeddedness. First verify whether the question asks only to classify the given objects or also asks for the converse construction; if the converse is not explicitly required and is not independently justified, prefer the classification that does not add it.

## Hypotheses
- Verify the hypotheses and domain carefully. Distractors often keep the theorem shape but alter the required assumptions.
- Check the quantified object and domain against the question before choosing a result. If an option adds an extra restriction, such as a subclass or a frequency cutoff, or substitutes a related object, such as a cover, an auxiliary or decorated object, or a local version for a global one, ask whether the question asks about that restricted or substituted object. A true bound for the restricted object is not evidence for the strongest statement about the full stated class. Prefer the option whose object, domain, and assumptions exactly match the question, unless the extra restriction is explicitly required by the result sought. Pay close attention to equality cases, extremal conditions, and whether a result applies to the full family or only a restricted subfamily.

## Final Answer
- Output the final answer as the single option label only.
