## F1：将未观察到目标提升为目标不存在

M11 使用 “when the target is absent”；M12 多次明确写当前 soapbar/butterknife “was absent”，并以此解释失败。这些执行只支持在所搜位置/预算内未找到，不能证明全环境没有目标。

具体反例边界：当前 P8/Q8 菜单中存在 `go to shelf 1`，两侧均未执行；还有长时间重复搜索。因此，不能从未找到 soapbar 推导对象不存在。禁止替代物的遵循观察仍然有效，但其条件应保持为“目标尚未观察到，而当前只看到近似对象”。

来源：本轮 bundle 全轨迹及菜单；[核对记录](results/semantic_evidence_checks.json)。这里没有读取隐藏环境状态来替代 Actor 可见事实。

## F2：新增了错误的历史动作

M12 将早期 heat-a-mug 任务描述为 Parent “took and heated a cup”。

- `S1_R03/P10:40` 是 take cup 1，`:41` 是 move cup 1 to cabinet 8；随后再次拿杯、搬入 microwave、开关/检查，但完整 50 步没有任何 heat 动作。
- 真正的 heat cup 2 出现在另一轮 `S1_R04/P1:31`。该条后半段叙述这一次加热是正确的。
- 原 M8 对 S1_R03 的表述是 took and moved a cup，没有将它称作加热。因此本轮在合并不同历史时引入了新错误，不只是重复原知识。

两次历史都存在替代物操纵，但不能将搬动与完成温变混为一谈。

## F3：用超出条款范围的响应解释编辑

M11 将 desklamp 与 pencil 的额外 desk 绕路作为 “Added open-surface exploration can add steps” 的例子。

- 额外一步本身真实：Q2 初始先去 desk，再找 pillow，总计 6 步；P2 为 5 步。Q5 先去 desk 再到 drawer，总计 6 步；P5 为 5 步。
- 实际 Diff 的 open-surface 条款只在 `General Non-Desklamp Retrieval, Cleaning, and Placement` 内。desklamp 原段保持不变，不能直接把 Q2 绕路算作该搜索条款被执行。
- 若怀疑提示间影响，那是未验证假设，不能在 Memory 中当成已观察到的条款响应。Q5 的范围适用，但单对选择差异也不足以确定由该条款造成。

此外，M11 开头称当前 Diff “retains earlier anti-cycling/step-budget language”。保留防循环与完成边界有文本依据，但当前 Parent/实际 Diff 没有历史中的显式 step-count/step-budget 优先条件。不能把更早版本出现过的指导默认为本次仍保留。

## F4：输出引用合法，但不足以保存所有叙述依据

全部 evidence 均存在；这只证明身份合法。本轮隔离 Memory 投影实际保留的当前执行只有 P7/Q7、P8/Q8、P10/Q10：

- M11 讨论 Q2/Q5 多走一步、其他简单任务不变以及全批 8/10，但未保存对应当前执行引用。
- M12 提及 clean-soapbar-to-toilet 精确目标成功，却没有 P9/Q9 引用。
- M10 概括全批多数动作合法及简单任务成功，证据数组仅有 Diff 与 P8/Q8。

完整 Replay 输入具有这些事实，原始实验也仍完整保存；问题是 knowledge 随引用装配进入未来 Preconditioner 后，部分具体陈述失去直接可核查的当前来源。未修改 ±2 窗口算法，也未在输出中人工补引用。

循环相关引用多集中于终局及少数非法动作。完整 action/feedback trace 仍能证明重复动作，但不能用它补出所有未保留的中间 observation/menu。程序“每条数字引用在详细窗口内”并不等价于“所有知识主张都有足够引用”。

## 与 R06 并列后的结论

| 现象 | R06 | 本轮 R05 |
|---|---|---|
| 核心响应能够抓到 | 温变减少冗余、搜索表现混合 | 替代物操纵仍在、搜索循环持续、非法导航仍在 |
| 细节事实被改写 | 错称两侧同一步取目标 | 把 S1_R03 搬杯写成加热杯 |
| 条件/归因边界不稳 | 局部省步与总步数变化混淆 | 未找到写成不存在；desklamp 绕路归入非 desklamp 搜索改动 |
| 后续证据视图的支持不足 | 部分条件缺少关键引用窗口 | 若干当前任务叙述未引用，未来视图没有该执行 |

已有两个案例提示：长上下文中的事实保持、条件限定和证据选择值得作为共同研究问题记录，但还不能由两个案例估计发生率或认定同一根因。本轮没有再出现 R06 那个具体的冷盘子效率混淆，不能把所有错误统称为同一个缺陷。

结构往返通过，语义不判整体通过。保留三个原样预览，不自动采用，也不因这些错误启动新机制、审核 Agent 或 Prompt 强化。后续 V23 对照继续使用冻结的原始 Memory。
