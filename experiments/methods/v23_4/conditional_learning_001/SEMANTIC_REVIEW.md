# 条件性认识候选语义比较

评价对象是原样首份合法输出：R05 attempt_002、R06 attempt_002。基线是 P4 学习 Prompt 的 P6 R05 attempt_002、R06 attempt_001。没有修改结果、择优语义重采样或再设计下一版 Prompt。

## R05

候选修订 M8、M6，并新增合法动作主题，共 3 个 Entry、6 条 Knowledge；隔离编号依次为 M10、M11、M12。基线只新增一条 Memory，含 4 条 Knowledge。候选体现了历史整合意图，但并没有稳定完成解释校准。

| 候选位置 | 正面价值 | 问题与采用影响 |
|---|---|---|
| M8 替换 / K1 | 保留历史 cool pan 的 pot 替代、R03 mug 的搬 cup 与 R04 mug 的加热 cup 差异；保留双方失败和归因限制 | 沿用旧的 `exact target was absent`，把未找到继续作为已知不存在。它不是当前观察可确认的适用条件，不能原样作为未来范围判断依据 |
| M8 替换 / K2 | 对比当前 knife 替代与 soapbar 不替代；新增当前 P6/Q6 成功获得正确 butterknife、8/8 步的能力保持，较基线覆盖更好 | 明确写当前 butterknife 和 soapbar 都 `was absent`。两侧初始菜单分别有未访问 cabinet18/shelf1；正确范围是未找到。该错误实质影响适用条件，妨碍整项采用 |
| M6 替换 / K1 | 历史 bread 修复与反向失败、plate 38 成功/50 失败均保留，且保留历史引用 | 仍是一段 1,874 字符的历史案例集中重述；长本身不是错误，但主要是完整复述，并未明显形成更清晰的条件区分 |
| M6 替换 / K2 | 将 bathtubbasin1/sinkbasin2 正确称为新增 locations，未再把 sinkbasin2 当新类型；记录持续循环和直接完成能力 | 完全遗漏当前 apple 的14→11及三步搜索改善；用 bowl-with-desklamp 的成功参与说明非 desklamp 搜索没有退化，范围仍不清晰。再次写 exact-target-absent，形成负面响应偏重 |
| 新合法动作 / K1 | Q8:39 与 P8:15 的非法导航及随后 examine 引用正确，不再把历史 drawer8 动作绑到 Q7:25 | 仍未识别 Parent P8:8 的合法直接 open；把主要注意力放在失败后 examine。没有新增收益的谨慎表述可保留，但机会与原有能力覆盖未完整 |
| 新合法动作 / K2 | 正确将 soapbar-to-toilet 8→6分解为 Parent 多一次格式异常和一次 inventory；不自动归因新增规则 | 对整体效率解释有价值；没有独立证明规则带来该差异，不应据此授予某种新策略效果。该条本身未发现阻断采用的核心事实问题 |

最直接的前后差别：基线 apple 至少在概览保留14→11并引用 P10/Q10；候选全提案既不讨论这对，也不引用它们。候选真正补回的是当前成功 butterknife 与历史 M6/M8 比较，不能用“总覆盖更多”抵消搜索主题关键正面响应的消失。

证据核验：P8:8 before 菜单只有 `examine/open cabinet 3`，无 `go to cabinet 3`，实际合法开柜；当前 P7/Q7 初始可去 cabinet18但未去，P8/Q8 初始可去 shelf1但未去；P10:9/Q10:6 取得 apple 后五个动作一致，14/11的差在搜索。以上均来自发送给模型的事实输入。

**R05 判断：不采用候选提案，也不据此替换 P4。** 有用增量是跨轮整合、正确对象能力保持和局部效率解释；阻断项是过强适用条件和关键正面比较遗漏。它们可能改变下一轮 D/S/C 决策，不属于只影响措辞的瑕疵。

## R06

候选修订 M7（温变）和 M10（搜索），隔离编号分别是 M12、M13，与基线的编号/主题顺序相反。以下按修订对象比较，避免同名新 ID 被误认为同一主题。

| 候选位置 | 正面价值 | 问题与采用影响 |
|---|---|---|
| M7 替换 / K1 | 保留当前 heat tomato 39/8、8/7，以及 cool plate 的局部少开门；保留历史直接持物温变模式 | 删除了基线明确的 cool tomato 两侧局部相同、整体差在搜索的限制。历史句子又将 pot/apple/egg/potato/tomato 的 Parent 一概写成插入与门循环，但历史 pot Parent 实际只开 fridge 后直接冷却。把不同局部响应压成同一种改善，削弱认识范围 |
| M7 替换 / K2 | heat plate 13成功/50失败不对称仍在；明确未触发不证明无效；R04 mug 的替代加热也保留 | 末句将这些 instances 概括为触发条件从未到达，没有继续限定是哪一侧；heat plate Parent 明明已取得目标并成功。前文正确，尾部范围仍含混。历史 R03 mug 不再在此重述，但仍在未修订 M11，不能说整个 Active 丢失 |
| M10 替换 / K1 | 保留 book 修复、tomato搜索更快，以及 cool plate 多探索导致整体8→9，与温变局部节省形成协调线索 | current creditcard 24→9、多实例能力保持被遗漏；对七个任务5/7→6/7的概览自身 Evidence 没覆盖全部七组。概览数字正确，但独立 Evidence 支持范围不足 |
| M10 替换 / K2 | 保留 apple 未取得目标、双方50步失败和防循环不可靠；没有直接声称该 apple 不存在 | 有限观察的范围比 R05 更稳，但“收益取决于目标在 sweep 到达的位置”仍主要是必要条件重述，较基线未带来明显新认识 |
| M10 替换 / K3 | 历史 butterknife/soapbar 两次修复、cool apple 38→46退化、7/10→9/10概览均保留 | 仍写历史 butterknife `no exact butterknife present`；旧错误解释继续继承。压缩保留了案例，却没有完成其条件校准 |

历史 pot 的事实特别清楚：S1_R03/P7:13取 pot，:14到 fridge，:15开门，:16直接 cool，:17到 countertop，:18放置；没有插入/取回或门循环。完整 trace 与14–18详细窗口都已在输入中。候选把它并入“Parent插入并循环门”的通用对照，属于观察关系的错误归并，不能用历史详情缺失解释。

当前 cool tomato P2:13/Q2:5取得目标，:15/:7冷却，之后操作相同；候选在搜索主题保留18→10，但没有像基线那样明确保留温变零新增局部收益。下一轮窗口相应只到 P2:14/Q2:6，冷却决策时的详细状态不再展开，动作序列仍保留。

**R06 判断：不采用候选替换 P4。** 历史 heat plate 的保持是延续基线已有能力；没有形成新增优势，同时丢失零局部收益及多实例能力保持，继承 absence 解释并新添不正确的历史温变归并。较短文本和较少引用不足以抵消这些退化。

## 对 D/S/C 的潜在影响

| 维度 | 可用增量 | 为什么尚不足以替换基线 |
|---|---|---|
| D 方向 | R05 同时保留拒绝近似物体与成功取得正确物体，有助于判断“继续强化措辞”是否足够；局部格式/搜索差异也更具体 | apple 的正面搜索响应消失，可能使方向判断偏向持续失败；R06把不同温变响应概括为同一种改善 |
| S 范围和强度 | 候选更常使用明确任务条件；heat plate 保留机会不对称 | 多处条件建立在未证明的 absent 上；删除温变能力本来已存在的零收益边界，可能诱导过度推广 |
| C 协调 | cool plate 的搜索额外开销与温变省步分别呈现，仍有联合响应参考价值 | 没有证明条款间因果交互，当前 creditcard 能力保持丢失，协调边界不比 P4 更完整 |

这些是对认识可用性的分析，没有运行下一轮 Preconditioner、Adjustment、Patch 或 Actor，因此不宣称实际 D/S/C 效果改善。

本轮采用判断不要求逐句无误。拒绝候选的依据是：有效比较保持发生实质退化、未支持的条件继续影响认识、成本没有获得相应收益。候选保留归档即可，不启动第二轮专项优化。
