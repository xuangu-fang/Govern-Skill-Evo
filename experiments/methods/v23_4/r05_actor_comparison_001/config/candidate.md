# Desklamp-Conditioned Inspection

Use this procedure only when the task explicitly requires inspecting, examining, or using an object under or with a desklamp. For ordinary put, clean, or transfer tasks where no desklamp is required, do not spend steps searching for, turning on, or co-locating with a desklamp; follow the general retrieval, cleaning, and placement procedure below instead.

## Procedure

1. Locate the desklamp and one matching target object.
2. Establish co-location at the desklamp's receptacle before completing the task:
   - If the target is already on the desklamp's receptacle, remain there.
   - If the target and lamp are on different receptacles, pick up one candidate target and carry it to the desklamp, or place it at the desklamp's receptacle.
3. Turn on the desklamp.
4. Pick up the target there (or keep holding it) and perform the requested look/examine, or use the lamp, while the target is held or otherwise co-located at that receptacle.

## Constraints

- Ensure the desklamp is on and the target is held or otherwise co-located at that receptacle before finishing.
- Inspecting the receptacle alone is not a substitute for interacting with the requested object.
- Do not repeatedly toggle the lamp while the target is at a different receptacle.
- Do not move the target away after turning on the lamp.
- Do not shuttle multiple same-type candidates between locations; remain at the lamp and finish with one co-located target.

## Admissible Actions

- Before committing to a navigation or manipulation command, verify that the command is present in the current admissible action list; if it is not, do not issue it.
- When a desired navigation destination is absent but a direct action on that receptacle is listed, use the direct action if appropriate; otherwise choose a different admissible action that advances the search or task.

## General Non-Desklamp Retrieval, Cleaning, and Placement

For ordinary put, clean, or transfer tasks where no desklamp is required, use this procedure instead.

1. Identify and search for the exact requested target. If it is not visible, search systematically: open any closed cabinet, drawer, or fridge immediately upon reaching it and inspect its contents before leaving, and include visible open surfaces such as tables, countertops, shelves, and sidetables rather than only closed drawers or cabinets. If an opened receptacle visibly lacks the target, leave it and choose a different uninspected candidate from the current admissible list; do not re-enter a location just left or repeat a short cycle among the same few locations. After checking receptacles of one type, move to a still-unexamined receptacle, preferring a type you have not yet tried, before re-checking a location that the current or recent observations show was already opened or seen to lack the target. Do not repeatedly check inventory while carrying nothing. Continue until the exact target is found or all plausible candidate receptacles have been inspected once.
2. Manipulate only the exact requested target category. When the task requests an exact object and that exact noun phrase has not been observed, do not acquire, clean, cool, heat, or place a different but related object as a substitute; for example, do not transfer a soapbottle when the task requests a dishsponge. If a container holds only a non-matching object, leave it without manipulating that object and continue searching for the exact target. Do not treat conditioning or placement of a non-target object as progress toward the task; only the exact requested object satisfies the goal. If the exact target has not yet been found, continue the systematic search rather than completing the transfer with a non-target object.
3. Acquire the exact target. If the task requires the object to be clean, carry it to an appropriate cleaning receptacle such as a sinkbasin and perform the clean action. If no cleaning is requested, skip the cleaning detour.
4. Go directly to the requested destination. Open it first if it is closed, then place or move the target there. Do not detour to unrelated receptacles or release the target before the requested placement is completed.

Keep the successful search, acquisition, and placement behavior used in non-desklamp transfer tasks.
