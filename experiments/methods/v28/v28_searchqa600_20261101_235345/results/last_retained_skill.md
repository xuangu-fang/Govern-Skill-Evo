# Question Answering Skill

## Answer Form

- When the question asks for an organization, work, person, place, or other named entity, give only the direct answer form; do not append a parenthetical abbreviation, expansion, translation, or explanatory gloss, and do not list aliases or alternatives inside the `answer` element unless the question explicitly asks for an abbreviation, full name, or definition.
- When a clue asks for a named entity and one clue-bearing passage supplies the name directly while another passage supplies a longer variant with an added generic type word or additional personal names, answer with the form used by the clue-bearing passage unless the question explicitly requests the longer or official name; do not expand a name merely because a fuller variant appears elsewhere. Except where a heading/title or parenthetical supplies a conventional familiar identifying form, this rule does not require replacing a conventional full given name with a nickname or abbreviated given-name form when a clue-bearing passage supplies that full given name; its target is appended type words or added name elements, not an abbreviated first name.
- When the context's heading/title or a parenthetical supplies a conventional familiar given-name form for a person and another passage supplies a different formal given name for that same person, prefer the familiar form for a bare identification question unless the question asks for the full/formal name or no familiar identifying form appears. Do not substitute a formal given name for a familiar identifying label merely because the formal name is conventional; this preference applies even when the formal given name is the conventional full name in an answer-bearing passage, and the caveat about not replacing a full given name with a nickname does not apply when a heading/title or parenthetical supplies the familiar form as an identifying label.
- If the context supplies a standard acronym or short name for an organization and uses it as a standalone name, prefer that short form alone over combining the full name and expansion.
- When a clue asks for a company or organization by its slogan or brand and the context uses a bare brand name as a standalone company name while other passages or headings append a generic business descriptor, answer with the bare brand alone unless the question explicitly asks for the full legal or official name; do not let a slogan-bearing passage that uses the longer form override this preference for the standalone brand.
- When a clue asks for a state university with an 'at [campus/city], not [other campus/city]' disambiguator and the context contains a campus-qualified branch formed by adding that campus/city to the state-university name, answer with the base state-university name alone (the name with the campus/city suffix removed) unless the question explicitly requests the branch, the specific campus, or the location itself rather than using it to identify the university. Do not append the campus/city qualifier merely because it appears in the clue or in an answer-bearing passage.
- When the clue asks for a specific person and the clearest answer-bearing passage presents that person's name with a conventional honorific or title as part of the name, include that honorific in the answer unless the question asks only for a surname, given name, or another partial identification, or asks for the person's role rather than identifying the person.
- When a clue identifies a person through a single-name character/title designation or dynastic reference and the answer-bearing context treats that single name as the requested designation, give the single name alone rather than adding a family or dynastic surname; still give a full personal name when the question asks for the person as an author, artist, or other full-name identification, and keep a conventional honorific only where the existing person-name rule calls for it.
- Do not append descriptive phrases such as the person's ship, nationality, or occupation when the named person is the requested answer; those details belong outside the final answer if explanation is needed.
- When the clue asks for a common noun or category, follow the grammatical number of the clearest definitional or naming passage rather than the clue's grammatical number or the mere presence of a plural elsewhere: if that passage gives a singular headword, answer in the singular even when the clue uses 'these' or other passages contain plurals; if it gives an established plural label, keep the plural. This takes precedence over any blanket preference for a plural standalone form.
- Do not automatically pluralize an attributive modifier; when the clearest definitional or naming passage supplies a standalone form that can serve as the category name, use that standalone form rather than an attributive modifier from another passage, and use the number established by that passage.
- When a clue asks for a term for a class, event, or process, and the context supplies a bare headword or generic noun in a definition while a heading or another phrase adds a possessor, object complement, or other specifying phrase, answer with the bare headword or generic noun alone unless the question explicitly asks for that named instance or full phrase; do not copy the longer heading/title or instance phrase into the answer element. For an action or process, retain the gerund or nominal form naming the action or process, including when used attributively in a heading/title and even when a base-verb form appears in a definition or example, and drop only the added specifying phrase; retain the ordinary singular-versus-plural headword rule for countable objects or categories rather than applying this preference to them.
