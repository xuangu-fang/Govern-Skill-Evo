# Live Mathematical MCQ Heuristics

## Option Comparison
- Compare all options before committing. The correct choice is often the strongest statement justified by the question, while nearby distractors are weaker, overstrong, or miss an equality case.
- When options differ mainly by scope or by an added classification clause, match each option's scope to the question. If the question quantifies over all objects in a class, do not select a version that silently restricts the result to a special subclass unless the hypotheses or a counterexample force that restriction. If the question asks for a classification and an option adds a converse ("and conversely every such object arises"), an extra exceptional family, or an additional structural clause, select that added material only when the requested classification actually includes it; otherwise choose the option with the same supported forward classification and no unsupported addition. Apply this scope check after removing unsupported additions; it does not override a compatible stronger-result meta-option—if no listed substantive option states the exact full conclusion requested, choose the compatible meta-option.
- Compare near-duplicate substantive candidates by isolating the single modifier that separates them, such as a full gradient versus one coordinate derivative, a local statement versus a universal-cover statement, "at most" versus "exactly/only", or the object named in the question versus a decorated version. Select the more modified or restrictive substantive candidate only when a hypothesis or standard theorem specifically requires that modifier; a request for the strongest statement does not by itself justify adding an unsupported restriction or replacing the named object. Prefer the direct substantive candidate over an unsupported modifier. This preference does not override the separate meta-option rule: if the direct substantive candidate is still weaker than the stronger result asserted by a compatible meta-option, select the meta-option. Keep the direct choice when no compatible meta-option and no theorem-supported modifier requires a change.
- Track exact quantifiers such as "there exists", "for every", "if and only if", and "exactly when".
- On a prompt that asks for the strongest, most complete, most general, exact, or equivalent statement, classification, or characterization—including a "which statement is valid" prompt whose options differ in strength—make a final triage of every substantive candidate before choosing when an option says that a remaining substantive option is correct but a stronger result can be proved. Classify each substantive candidate as (i) an exact statement of the requested conclusion, (ii) a removable restriction or weakened quantifier, such as a special class, extra hypothesis, one direction, lower regularity, an almost-everywhere version, or an existence or necessary-condition claim, or (iii) an unsupported overstatement with an added equality, global characterization, or regularity clause not forced by the hypotheses. Do not choose the most detailed, technical, or restrictive substantive option by default. Before choosing any substantive option, try to state the exact substantive theorem that would make the meta-option false: it must include every conclusion, bound, quantifier, and scope required by the question and must not add an unsupported converse, uniformity, exceptional family, or regularity clause. If no substantive option can be identified as that exact sharp theorem, select the stronger-result meta-option when the asserted stronger result is compatible with the stated hypotheses and quantifiers; do not select it merely because it is present. If such an exact substantive option is present, keep that substantive option instead; also prefer it if the asserted stronger result conflicts with the hypotheses or quantifiers.

## Theorem-Level Precision
- Check whether an option weakens the conclusion by dropping a characterization, equality clause, or full equivalence.
- Check whether an option overstates the theorem by upgrading regularity, removing scale restrictions, or changing an existential statement into a universal one.
- When two options share the same necessary divisibility condition but one asserts actual homotopy equivalence while the other asserts p-local equivalence at every prime, do not upgrade to actual homotopy equivalence from the divisibility condition alone. Check whether the stated invariants determine only the local factors; if they do, choose the p-local formulation as the strongest justified conclusion, unless the hypotheses or a standard integral obstruction result also establish the global equivalence.

## Hypotheses
- Verify the hypotheses and domain carefully. Distractors often keep the theorem shape but alter the required assumptions.
- Pay close attention to equality cases, extremal conditions, and whether a result applies to the full family or only a restricted subfamily.

## Final Answer
- Output the final answer as the single option label only.
