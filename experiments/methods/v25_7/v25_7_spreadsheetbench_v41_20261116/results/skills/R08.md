# Spreadsheet Manipulation Skill (xlsx)

## Overview
This skill guides agents in manipulating Excel (.xlsx) spreadsheets using Python.

**Primary libraries**: `openpyxl` (structure-preserving read/write), `pandas` (data transformation).
Never use any other third-party libraries.

---

## Common Workflow

1. **Explore** the input file: list sheets, inspect headers, check dimensions.
2. **Write `solution.py`** with `INPUT_PATH` and `OUTPUT_PATH` defined at the top.
3. **Execute** `python solution.py` and verify the output file was created.
4. **Confirm** the target cells/range contain the expected values.

---

## Row Deletion

When the instruction asks to delete rows (`delete these rows`, `delete every row where ...`, or `delete everything above <marker>`), remove the rows physically; do not merely set their cells to `None` or blank. Gather the worksheet row indices to remove and either call `ws.delete_rows(index)` for each index from the highest downward, or rebuild the worksheet by writing only the surviving rows contiguously from the first retained row. Use blank or `None` writes only when the instruction explicitly says to clear, empty, or blank out cells.

For `delete everything above the first occurrence of <marker>`, scan the full specified target column case-insensitively to locate the marker row, then delete the rows above it while keeping the marker row and every row below it unchanged. Do not also delete leading blank rows that merely sit above the marker unless the instruction explicitly says to remove them.

After saving, reload `OUTPUT_PATH` with `openpyxl.load_workbook(..., data_only=True)` and confirm that the retained rows occupy the collapsed positions and that no stale record remains below the last survivor. If stale records remain, delete them from the bottom upward, save again, and repeat the reload check.

## Keyword and Text Matching

When the instruction says a cell `contains` a keyword, says to `look for` a text, or allows partial matching/prefixes/suffixes, test with case-insensitive substring matching after normalizing surrounding whitespace. When a match is found, replace the whole target cell with the specified new value rather than requiring the keyword to be the entire cell. Use exact equality only when the instruction explicitly says the cell equals/is exactly the text. Keep this text-matching rule separate from any numeric classification of a companion cell. This rule is mandatory for keyword and text-search conditions. Exception: if the instruction explicitly requires exact match/equals, do not match surrounding text. Branch: if no row matches, leave the destination region unchanged or blank as instructed.

## Period-End Counts

For counts labeled `open by/of the end of [month or period]`, treat the period-end label as controlling. Include a record only when its created/start date is on or before the period end and its closed/end date is blank or strictly after the period end; exclude records closed on or before the period end. Do not apply a first-day rule merely because the explanatory sentence says the record was `not closed before the first day` or was open at some time during the period; use the first-day boundary only when the task asks for records that were open at any time during the period and does not ask for the end-of-period count. Apply the same cutoff consistently across every answer cell.

## Library Selection

| Use case | Library |
|----------|---------|
| Preserve formulas, formatting, named ranges | `openpyxl` |
| Bulk data transformation, aggregation, sorting | `pandas` → write back with `openpyxl` |
| Simple cell read/write | `openpyxl` |

**Warning**: `pandas.to_excel()` silently destroys existing formulas and named ranges.
When writing back to a spreadsheet that contains formulas, always use `openpyxl.save()`.

## solution.py Template

```python
import openpyxl
import pandas as pd

INPUT_PATH  = "..."   # set to the actual input path
OUTPUT_PATH = "..."   # set to the actual output path

wb = openpyxl.load_workbook(INPUT_PATH)
ws = wb.active  # or wb["SheetName"]

# --- perform manipulation ---

wb.save(OUTPUT_PATH)
```

## Formula Cached Values and Verification

- Grading reads the saved workbook with `data_only=True`, while `openpyxl` writes a formula without computing or storing its result. If the task requires a formula in the answer region, keep the formula and also compute its expected result in Python so the saved cell carries a readable cached value.
- After saving to `OUTPUT_PATH`, reload the saved file with `openpyxl.load_workbook(OUTPUT_PATH, data_only=True)` and read back every answer-region cell intended to be written. Compare each read-back value with the intended stored value: a formula's cached result, a literal, or the required placeholder rather than the raw arithmetic where a placeholder rule applies. Allow a legitimately blank result.
- If an intended cell reads as empty/`None` or differs, repair it and save again. For a required formula, resolve the worksheet part from the workbook relationship, normalize a leading slash or an existing `xl/` prefix, and rebuild that cell's XML with both the `<f>` formula and the computed `<v>` cached result, dropping any string type attribute for a numeric result. If the task permits a literal instead of a formula, write the computed value directly. Re-read after the repair.
- If the required check still fails for a cell, raise an execution error naming that cell and the discrepancy instead of submitting. An openable output file or a clean exit status does not by itself show that an answer cell holds the intended readable value.

## Output Requirements

- Save the result to `OUTPUT_PATH`.
- When the instruction gives a start cell for the answer (for example `starting at <cell>` or an equivalent phrase), place the requested header row at that exact cell even when the stated answer region extends one row above or to one side; do not shift the output upward or leftward to fill those margin cells. Put data immediately below the header in the stated row order. When the instruction lists a custom item/row order, sort the listed items by that order first and use a deterministic fallback only for items not covered by it; do not rely on first-appearance order for the listed items. If the instruction requires formatting for the entire answer range, apply it across the stated range including blank margin cells. When only an answer region is given and no start cell is stated, use the region's top-left cell as the anchor.
- Do not hardcode row counts or column letters — iterate over actual rows in the workbook.
- Preserve sheets and cells not mentioned in the instruction.
