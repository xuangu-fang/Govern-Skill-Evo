# DocVQA Skill

## Visual Evidence Discipline
- Read the document carefully before answering.
- For questions using 'when', 'what date', or 'date and time', identify the named event and read the full printed temporal expression attached to that event. Return the complete printed date, plus the time only when the question requests a time, rather than shortening a full date to a year or substituting a year from a nearby heading, footer, or different event. If the question explicitly asks only for a year, or the named event's printed value is only a year, return that year. Preserve the printed wording and punctuation of the selected temporal value. Keep this separate from the page-number rule and from counts, names, and codes.
- Before finalizing, identify what the question asks for: an amount, name, title, count, code, number, list, and so on. Return only that value, not the table/figure/column/row label used to locate it and not an unsolicited equivalence, conversion, alternative representation, explanation, or parenthetical note.
- Use identifiers in the question, such as a table number, building number, study number, or record label, to locate the answer. Do not repeat them in the final answer unless the question explicitly asks for the identifier or the identifier is itself part of the requested title/name.
- Preserve text that is genuinely part of the requested value: official names and embedded abbreviations, required units, necessary qualifiers, and all items when the question requests a plural or list answer.
- When the document presents both a container label and its content, or both a requested value and an adjacent converted/equivalent value, prefer the content/value alone. Apply the same scope discipline when a title, name, or amount is embedded in a larger heading or cell.
- When the question asks for a page number, page no., or the page number of a named entry, return the numeric page value alone and omit the label word "Page" and any total-page wording such as "of N", unless the question explicitly asks for the full pagination statement or the page identifier itself is a nonnumeric code. For this label portion, this page-scope rule takes priority over the general preference to copy an exact span; preserve the digits and any genuinely requested page identifier. Do not extend this to questions requesting dates, names, counts, page ranges, or full printed pagination phrases, and do not add narration or alternative values. Existing correct direct extractions and full-phrase cases explicitly requested by the question remain unchanged.
- When the question names a record/entity and a field, first identify the exact row or entity label and the exact column or field label the question asks for. Read the value at their intersection or beside the matching field label; cross-check that the candidate's adjacent label or header matches the question, not merely a similar nearby label.
- For contact information, distinguish exact field labels such as fax, telephone, toll-free, e-mail, and address, and return only the value attached to the requested label. Do not return a different number or code merely because it is nearby or has the same format.
- If two candidates look plausible, prefer the one whose exact row/entity and column/field labels match the question. If none matches exactly, return the best-supported single value rather than switching to a different field or listing alternatives.
- This procedure is especially applicable when the question includes a specific record identifier or when the page appears to contain several codes or numbers of the same format. It should not interfere with simple, directly stated single-value questions, and row/column narration must not be added to the final answer. Existing correct direct extractions remain unchanged.

## Exact Answer Discipline
- Copy names, numbers, and dates exactly from the document whenever possible.
- For questions requesting an amount, price, cost, or other monetary value, return the numeric value as printed in the selected cell or field, retaining any visibly attached currency symbol or unit marker as described below, except when the question explicitly states the currency or unit.
- When the question explicitly states the currency or unit (for example, 'in $', 'in USD', or 'in dollars'), return the printed numeric amount alone and do not add or repeat that currency symbol or unit; keep the printed digits, decimal point, grouping commas, and displayed decimal places. If the question does not itself specify the currency and the selected value has a visibly attached currency symbol, preserve that symbol as currently instructed; if the question explicitly asks for the printed symbol or the full printed amount, follow that request. Do not add a currency symbol or unit that is not visibly attached.
- Add a currency symbol or other unit marker only when that marker is visibly attached to the selected value and the question does not already state that currency or unit; do not infer or add it solely because the question asks for an amount or because the document contains other currency signs.
- If the selected value is visibly printed with a symbol, preserve that symbol and its printed spacing exactly unless the question explicitly states the currency or unit or explicitly asks for the printed symbol or full printed amount; do not add a second representation, conversion, or parenthetical alternative.
- This amount-specific rule, including the explicit-question exception, is scoped to monetary values and does not authorize stripping percent signs or units in other contexts, or otherwise altering dates, names, codes, or other exact values. Counts, percentages, dates, names, and codes remain governed by the existing exact-copy rules, and this exception does not change the page-number rule.
- When the requested value is itself quoted or contains quoted wording or a quoted title, reproduce that quoted portion with ordinary straight double quotation marks (") rather than typographic curly quotes (“ ”), while preserving the exact quoted words, capitalization, spacing, and internal punctuation. Apply this only when quotation marks are part of the requested value or exact span; do not add quotation marks to unquoted answers, do not convert apostrophes, and do not otherwise normalize names, numbers, units, percent signs, parenthetical qualifiers, or full-sentence answers. Existing successful direct extractions remain unchanged, and if the question explicitly requires a different typographic form, follow that explicit requirement.
- Prefer direct extraction over paraphrase.
- For questions asking for a business segment, course, event, title, designation, product category, or similar printed named entry, return the exact printed span of the selected entry. Preserve its internal wording and grammatical number exactly, without pluralizing or singularizing it to fit the question. If the same entry or cell visibly includes a trailing schedule/day notation attached to the name, keep that notation as part of the entry when the question asks for that listed entry; do not drop an attached same-entry suffix. Conversely, do not merge a separate schedule, day, time, row/column label, or adjacent field that the document presents apart from the requested name, and do not add such a field merely because it is related or because the question mentions a schedule. If the question asks only for the name and the schedule is separately presented, return the name alone; if it asks for the full listed entry and the printed entry includes the notation, return the full printed entry. This applies to named entries, not to the object noun of a measurement question, and it does not authorize adding labels or narration. Existing correct full-title and designation extractions remain unchanged.
- Before finalizing, compare the answer against nearby alternatives and keep the best-supported exact span.
