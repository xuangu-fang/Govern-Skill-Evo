# DocVQA Skill

## Visual Evidence Discipline
- Read the document carefully before answering.
- Prefer the smallest exact text span that answers the question: one complete requested value, not a collection of equivalent representations. For an amount or monetary value, first check whether the question's own wording already names the currency unit (for example, 'in $', 'in dollars', or 'in euros'). If it does, treat that unit as supplied by the question and return the numeral alone, omitting the currency symbol or currency word, unless the question explicitly asks for the printed notation, the full displayed amount label, or multiple representations; this question-supplied-unit rule takes precedence over the general preference to keep a visibly attached currency symbol. Preserve the numeral exactly, including commas and decimal points; do not convert, round, restate, or add a separate equivalent. If the question asks 'how much' without naming a currency, or otherwise does not name the currency, return the numeral with only a currency symbol or unit visibly attached to that same numeral; if the currency symbol appears only in a column heading, table caption, separate label, or otherwise outside the selected entry, do not prepend or append it. When the question does not name the currency, do not add a currency symbol solely because the question implies one; keep a symbol only when it is visibly printed as part of the selected value. For a measurement, date, or other number, return the single directly stated span that answers it and keep only the unit or wording visibly belonging to that span. Do not append a separate converted amount, alternate unit, restated numeral, or explanatory equivalence unless the question explicitly asks for multiple representations. Treat a visible clause marked as an equivalent or conversion (for example, 'equivalent to' or a second currency amount) as outside the requested answer unless the question asks for that equivalence. If several representations appear, select the one best supported by the question's wording and nearby label rather than concatenating them. Preserve terse numeric extraction when the question or document uses the number alone, and do not strip required identifiers or qualifiers that are part of the requested value.
- When the question asks for a measured attribute of an object named in the question (for example, a height, weight, or dimension), return the numeral with only the unit visibly attached to that numeral. Do not append the object or category word from the same row, cell, or sentence merely to make the answer a fuller description; the requested value ends at the measured numeral plus its attached unit. Keep a unit such as '%' when it is visibly part of the selected value and the question's own wording does not already supply that unit; when the question's wording itself supplies the unit (for example, 'what %', 'what percentage', 'in $', or 'in dollars'), follow the existing question-supplied-unit rules and return the numeral alone. Exception: if the question explicitly asks for the item description, the complete printed column or cell entry, or multiple representations, include that requested wording. This boundary does not remove units or qualifiers genuinely part of the measured value, and it does not alter page-number, role-title, or label rules.
- For a page-number question, return the numeral itself as the complete requested answer. Exclude a surrounding printed label such as 'Page' and a trailing page-count phrase such as 'of 2' unless the question explicitly asks for the complete printed page designation, the full page label, or multiple representations. Preserve any identifier or qualifier that is genuinely part of the requested page value. If the visible structure does not make clear whether the question requests the numeral alone or the whole printed label, use the question wording: a request for the page number or page no indicates the numeral; a request for the page label or full printed designation may include the label.
- When the question identifies an element by a label, number, or caption marker (such as a table, figure, or section identifier) and asks for that element's title, name, or value, answer with the title, name, or value itself and exclude the retrieval label or caption prefix unless the question explicitly requests the label too. Do not treat an adjacent label as part of the answer merely because it is next to the requested content. Preserve the full requested title or name, including internal qualifiers that belong to it. Use the question's requested entity and the visible label/content structure to decide this boundary.
- For questions that ask for a person's designation, position, job title, or role, treat the role title as the complete requested answer and stop before a separately printed organizational affiliation chain (such as division, institute, department, or employer names). Apply this only when the question asks for the role/designation itself, not when it asks who holds an office, asks for the employer or affiliation, or asks for a full organization/institution name. Preserve internal qualifiers that are genuinely part of the title, preserve name suffixes and full officeholder names when the question asks who someone is, and preserve full printed organization names when the question asks for a company or university. Do not shorten an explicitly requested full name or an internally qualified title merely because it is long; omit only separately printed affiliation material that the question did not request. If the visible structure does not distinguish the role title from the affiliation, use the question's requested entity to choose the smallest coherent title span.
- When the question asks which brand, service, product, or named advertised entity is featured, return the core printed brand or proper name and stop before separately printed service descriptions, branch names, or geographic qualifiers. After selecting that core name, copy its letters exactly. Keep the full printed organization name when the question asks for the company's name, full or legal name, employer, affiliation, or when the visible name is one indivisible proper name. Do not apply this shortening to explicitly requested full organization names, titles, or person designations, and do not strip an attached qualifier that is genuinely part of the requested brand.
- When several nearby strings look similar, choose the one whose surrounding labels or layout best match the question.
- For a selected named entry, if the question asks for a course, program, section, named record, or similar entry, inspect the complete printed line or table/form cell for a compact trailing qualifier or code visibly attached to that same entry. When the entry presents the requested name followed by an attached schedule, day, section, version, or similar code within the same field, preserve the whole printed entry rather than stopping after the alphabetic title. Do not add a code that appears in a separate column, caption, retrieval label, page label or count, or separately printed affiliation chain; return the name alone when the visible layout clearly separates the code as an independent field not requested by the question. This conditional preservation rule does not require expanding every proper name with adjacent administrative text.

## Exact Answer Discipline
- For a yes/no question, return only the single affirmative or negative word (yes or no) without a terminal period, explanation, or restated condition. Keep the answer grounded in the visible evidence and preserve any qualifier the question actually requires. Do not apply this punctuation rule to quoted document spans, names, numbers, dates, or other requested values.
- Copy names, numbers, and dates exactly from the document whenever possible.
- For identifiers, codes, program numbers, reference numbers, and similar requested labels, return the printed character sequence as one contiguous value without inserting slashes, spaces, hyphens, decimal points, or other separators that are not visibly present. If a separator is visibly part of the printed identifier, preserve it exactly; do not strip it or replace it with another character. Do not merge or split characters merely to make the string look like a date, fraction, or grouped number. If the visible grouping is ambiguous, copy the characters in their apparent left-to-right order and do not introduce punctuation to explain them. This is a transcription rule for requested labels, not a general instruction to shorten or normalize numbers, dates, measurements, or expressions; continue to preserve required units and qualifiers and to select the best-supported exact span.
- For a percentage question whose wording already contains the unit, such as 'what %' or 'what percentage', treat the percent sign as supplied by the question and return the numeral alone, omitting the '%' symbol from the submitted answer, unless the question explicitly asks for the printed notation, the full displayed label, or multiple representations. This is a scoped clarification of the existing unit/span guidance, not a general normalization rule: continue to keep a document-stated currency symbol or other unit when the question asks 'how much' or otherwise does not name that unit, and continue to exclude converted or alternate representations. Preserve exact numerals and any identifier or qualifier that is genuinely part of the requested percentage value.
- Prefer direct extraction over paraphrase.
- Before finalizing, compare the answer against nearby alternatives and keep the best-supported exact span.
- When preserving a selected named entry that includes an attached schedule, day, section, version, or similar code, copy the whole entry exactly as printed in that field; do not shorten it to the alphabetic title. Do not include a code from a separate column, caption, retrieval label, page label or count, or affiliation chain, and return the name alone when the code is visibly independent or not requested.
