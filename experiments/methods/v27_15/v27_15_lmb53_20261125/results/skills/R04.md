# Live Mathematical MCQ Heuristics

## Option Comparison
- Compare all options before committing. The correct choice is often the strongest statement justified by the question, while nearby distractors are weaker, overstrong, or miss an equality case.
- Whenever an option states that a stronger result can be proved, treat it as a live catch-all candidate even if the stem says 'which statement holds', 'which statement is equivalent', or asks for a complete description rather than literally asking for the strongest statement. Check whether each concrete choice states only a weaker, endpoint-free, or qualified version of the result; before selecting a concrete option, identify the exact extra strengthening it adds beyond the displayed hypotheses, such as an equality or equivalence claim, a uniform estimate, an all-points or all-primes assertion, a finite-cover assertion, or an unqualified global conclusion. If a concrete choice is true but none states the sharp conclusion, or if that extra strengthening cannot be certified from the problem data, do not choose the concrete option merely because it is more detailed or familiar; select the catch-all option. Do not choose a detailed concrete statement merely because it sounds stronger or more complete than the catch-all. When no catch-all option is present, use ordinary mathematical comparison.
- Track exact quantifiers such as "there exists", "for every", "if and only if", and "exactly when".
- In classification or complete-list choices, distinguish the allowed cases from a converse asserting that every parameter value in the displayed form occurs. Unless the statement or a theorem explicitly proves realizability of every such value, reject an option that appends an unproved converse such as 'every such parameter actually occurs'; prefer the version that gives the exact possibilities or conditions without that converse.

## Theorem-Level Precision
- Check whether an option weakens the conclusion by dropping a characterization, equality clause, or full equivalence.
- When deciding whether an induced map is an embedding or is injective, require an actual pair of distinct objects with the same image before accepting a non-injectivity claim. A general operation that could identify classes is not evidence that it does so here. If no concrete collision is available and the induced map is algebraic or Poisson, prefer the structural embedding statement over a claim that the map is only a non-injective Poisson map.
- Check whether an option overstates the theorem by upgrading regularity, removing scale restrictions, or changing an existential statement into a universal one.

## Hypotheses
- Verify the hypotheses and domain carefully. Distractors often keep the theorem shape but alter the required assumptions.
- For consistency-strength or independence questions, separate a consistency assertion, meaning there is a model of the axiom in which the configuration holds, from an impossibility assertion, meaning no model of the axiom contains it. Do not choose an option saying an axiom forbids a configuration merely because the configuration is unusual; an impossibility requires a consequence or derivation from the axiom. If the alternatives are compatibility with the axiom and exclusion by the axiom, check whether the exclusion is actually forced; otherwise select the compatibility statement as the stronger supported consistency claim.
- Pay close attention to equality cases, extremal conditions, and whether a result applies to the full family or only a restricted subfamily.
- Check that an option answers the exact object and full scope requested. An option that adds a restriction not asked for, such as bounded frequency support or a compact parameter interval, does not establish the strongest unrestricted assertion. Likewise, a statement about a decorated or auxiliary version is not a statement about the requested underlying object unless the question asks for it. Prefer the unrestricted or direct statement for the requested object when it is supported, and choose a restricted version only when the hypotheses or sharp theorem genuinely require it.

## Final Answer
- Output the final answer as the single option label only.
