# DocVQA Skill

## Visual Evidence Discipline
- Read the document carefully before answering.
- Prefer the smallest exact text span that answers the question.
- When several nearby strings look similar, choose the one whose surrounding labels or layout best match the question.

## Exact Answer Discipline
- When the selected answer span is wrapped in double quotation marks, or contains a quoted phrase, and the visible marks are rendered as curly or typographic quotation marks, return the same quoted content with plain ASCII straight double-quote characters instead. Keep the marks present exactly where they enclose text, and preserve the words, capitalization, spacing, and all other punctuation; this is only a glyph-style normalization for double quotation marks, not permission to remove enclosing quotes or to alter apostrophes or other characters. Do not add quotation marks when the selected span is not visibly quoted. This applies to both a single quoted expression and a list of quoted items, joined as the document prints them.
- When the question asks for a page number or page no and the visible page identifier is a pagination pair such as `N of M` or `Page N of M`, return the current-page component alone; do not return the total-page component, join the two numbers, or reproduce the whole running header/footer. Determine the current component from the visible layout and convention (typically the first number in a conventional footer), not from an assumed total. If the question explicitly asks for the total number of pages or the complete pagination label, follow that request instead. For a standalone page number in a labeled field, copy the printed span exactly as before. Keep punctuation belonging to the selected page-number component; remove only the pagination total and connecting wording as surrounding material.
- Copy names, numbers, and dates exactly from the document whenever possible.
- Prefer direct extraction over paraphrase.
- Before finalizing, compare the answer against nearby alternatives and keep the best-supported exact span.
- Return one answer value inside a single <answer>...</answer>. When the question asks for one field that the document prints more than once (a main figure plus a parenthetical or converted figure, or a note-style annotation beside it), answer with the one rendering attached to the label, row, heading or wording the question names, and omit the others: do not join two renderings of the same field, do not convert, and do not add explanations, derivations or comments after the value. If two renderings remain equally plausible, still return only one of them rather than a compound answer. This one-value rule concerns a single requested field: when the question itself asks for several items (a plural or list question, or several named items held in one field), give each requested item as printed, joined as the document prints them, and do not drop the extra items.
- Preserve as printed whatever punctuation, spacing, parentheses or suffixes belong to the chosen span: keep internal punctuation of names and identifiers, keep parentheses that are part of a printed number, and keep a multi-word name whole. Trimming means removing content around the answer, not editing characters inside it.
- For a displayed short text span (such as a title, tagline, slogan, or quoted label), keep enclosing quotation marks that visibly wrap the chosen span as part of the printed answer; do not trim them as surrounding material. Do not copy quotation marks that appear only in the question, and do not add enclosing quotation marks to a span that is not visibly quoted. If the visible layout leaves it unclear whether the marks belong to the selected span, choose the best-supported single reading rather than returning alternatives or explanations. This applies only when the marks are part of the chosen span and does not change the one-value rule, the treatment of several requested items, or the preservation of other printed punctuation and suffixes.
- Unit handling for quantity questions: when the question wording or the field label / column heading already names the unit or quantity type (weight, page number, count, percentage, rate), return the printed value from that cell alone — do not re-append the unit, spell it out in words, add a currency symbol, or convert to another unit. Add a unit only when the question supplies none and the selected span visibly prints the value and unit together, in which case keep them together exactly as printed. When the question already carries the unit, the printed numeric characters are the complete answer.
