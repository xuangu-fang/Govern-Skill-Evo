# Spreadsheet Manipulation Skill (xlsx)

## Overview
This skill guides agents in manipulating Excel (.xlsx) spreadsheets using Python.

**Primary libraries**: `openpyxl` (structure-preserving read/write), `pandas` (data transformation).
Never use any other third-party libraries.

---

## Common Workflow

1. **Explore** the input file: list sheets, inspect headers, check dimensions.
2. **Write `solution.py`** with `INPUT_PATH` and `OUTPUT_PATH` defined at the top.
3. **Execute** `python solution.py` and verify the output file was created.
4. **Confirm** the target cells/range contain the expected values.

---

## Library Selection

| Use case | Library |
|----------|---------|
| Preserve formulas, formatting, named ranges | `openpyxl` |
| Bulk data transformation, aggregation, sorting | `pandas` → write back with `openpyxl` |
| Simple cell read/write | `openpyxl` |

**Warning**: `pandas.to_excel()` silently destroys existing formulas and named ranges.
When writing back to a spreadsheet that contains formulas, always use `openpyxl.save()`.

### Formula-Safe Source Reads

When an instruction depends on the calculated result or the error status of a source cell that
may contain a formula, load a second `data_only=True` view of the workbook and use its cached
value for that computation or conditional decision — for example, to detect an error value such
as `#N/A`, or to decide whether a computed result is zero or blank. Use the normal
(formula-preserving) view for structural reads and for all writes so required formulas are
preserved. Do not treat a formula string as the numeric or text result; if no cached value
exists, handle that case explicitly rather than silently writing the formula text into the
answer cell.

---

## Category-Specific Conditions

When an instruction imposes a category- or column-specific condition — for example counting
only positive values for one error code, or applying a warehouse, date or other criterion that
the surrounding columns do not use — apply that condition in every computation path,
including when the other totals come from cached or precomputed aggregate cells.

- Never obtain such a component by summing cached aggregates that mix included and excluded
  rows: recompute it from the underlying source rows with the predicate applied, then combine
  it with the other totals.
- Restrict the condition to the category or column it names and leave the other columns'
  calculations unfiltered.

## solution.py Template

```python
import openpyxl
import pandas as pd

INPUT_PATH  = "..."   # set to the actual input path
OUTPUT_PATH = "..."   # set to the actual output path

wb = openpyxl.load_workbook(INPUT_PATH)
ws = wb.active  # or wb["SheetName"]

# --- perform manipulation ---

wb.save(OUTPUT_PATH)
```

---

## Output Requirements

- Save the result to `OUTPUT_PATH`.
- Do not hardcode row counts or column letters — iterate over actual rows in the workbook.
- Preserve sheets and cells not mentioned in the instruction.

### Answer-Region Writes

Treat any existing answer region as a destination that may contain sample, placeholder, or
partially completed output. Recompute the requested result from the workbook's source data on
every run; do not guard the computation with a check such as 'if the destination is empty' or
otherwise skip writing because values already exist. Overwrite the required cells or records.
When the newly derived result is shorter than the existing content in the same answer region,
clear the leftover values there so stale rows cannot remain. Clear values only, without deleting
rows or columns or disturbing formatting, and leave cells outside the requested answer region
unchanged.
