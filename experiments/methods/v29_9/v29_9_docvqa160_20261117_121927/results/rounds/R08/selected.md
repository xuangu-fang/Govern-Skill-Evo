# DocVQA Skill

## Visual Evidence Discipline
- Read the document carefully before answering.
- Prefer the smallest exact text span that answers the question.
- When several nearby strings look similar, choose the one whose surrounding labels or layout best match the question.
- When a company or organization name is requested and the document appears to contain more than one corporate name (for example, a parent or holding entity, an operating subsidiary, a division, a letterhead or logo, a signature block, or body text), first decide which named entity is the subject from the question's role or relation (employer, issuer, operator, predecessor, acquired company, and similar) and from the surrounding visible labels or sentence.
- Return the name tied to that subject or relation. Do not assume the largest, first, most prominent, or letterhead/logo name is the answer when a different corporate name is the one described by the requested field.
- If the question has no relational qualifier and simply asks for "the company," prefer the corporate name in the principal identifying statement or main body that names the document's subject over a secondary parent, holding, or logo name; if visible role labels distinguish those roles, use the labels instead of guessing. Return only one corporate name; do not concatenate two names or add a parenthetical alternative.
- If the question asks for a person's employer or the company associated with an event, select the company linked to that person or event rather than the document's general corporate heading.
- After selecting the field that answers the question, re-read the chosen span at glyph level before finalizing. For proper names, alphanumeric identifiers, numeric amounts, and dates, compare the entire token with the visible source rather than relying on the first or last character, a familiar spelling, or world knowledge.
- Watch for characters easily confused in small or degraded print, such as letter/digit lookalikes and similarly shaped digits, and for omitted or transposed characters. If the same token appears in a second visible place, such as a header, summary, footer, or related field, use that occurrence only as a cross-check for the selected value; when occurrences conflict, keep the one tied to the question's label or answer field.
- Return one exact span and do not append alternatives or explanatory notes. Do not let this verification change answer scope: if the chosen span is visibly a different field or a longer entity than the question asks for, resolve that scope issue first. Apply the check with higher priority to short tokens where one character changes the value; for longer phrases, preserve the exact printed wording without expanding it.

## Exact Answer Discipline
- Copy names, numbers, and dates exactly from the document whenever possible.
- For a monetary amount or measured value, the answer should be the value as printed in the selected answer field. Keep a currency symbol, unit, or suffix only when it is visibly attached to that value; do not prepend a symbol or unit supplied only by a column heading, adjacent label, section text, or an assumption about the question.
- Do not strip a symbol or unit that is part of the chosen printed value, and do not append a second equivalent representation. If the document offers both a symbol-bearing and a bare equivalent, return the representation that the answer field and question support rather than combining them. This is a preservation rule about the selected field, not a general instruction to normalize, convert, or remove all symbols.
- If the question names a form that is visibly present in the answer field, follow that printed form; otherwise return the exact selected value.
- When the requested value appears in more than one equivalent representation in the same answer area, return only the single representation that directly answers the question; do not append a parenthetical, numeric, or otherwise secondary restatement merely for completeness.
- If the question explicitly asks for a particular form, use that form; otherwise use the primary full value printed in the relevant answer field and keep any unit belonging to that single form. Preserve punctuation integral to the value itself, such as parentheses within a phone number; avoid duplicate equivalent representations without removing meaningful characters. For a count question, the count-span rule below takes precedence over the general full-value preference.
- For a count question ("how many ...") whose best candidate span contains both a quantity and the counted noun, return the quantity alone and omit the repeated object/category label when the document also prints that label nearby. Keep the printed count form (digit or word). Do not apply this to units or suffixes integral to the requested value (measurement unit, time-of-day marker, currency symbol, and similar); keep them. If the question asks for the full label or object name as part of the requested value, return the full requested span. Do not invent a count or drop an integral unit.
- Prefer direct extraction over paraphrase.
- Before finalizing, compare the answer against nearby alternatives and keep the best-supported exact span.
- When the final answer is a phrase enclosed by quotation marks (for example, a tagline, slogan, or heading) and those marks merely enclose the phrase rather than belonging to the name or value, keep the phrase and render the enclosing marks as plain straight ASCII double quotation marks, using the same straight form for both opening and closing. Do not use curly or typographic quotation marks for these enclosing marks, and do not drop the enclosing marks in this situation.
- This is a character-level formatting rule for enclosing quotation marks only. Do not alter words, capitalization, or punctuation that is integral to the answer, such as a comma, period, hyphen, or an apostrophe inside a name or value; keep those exactly as printed.
