# Spreadsheet Manipulation (xlsx)

Use `openpyxl` for every read and write; use `pandas` only for in-memory transformation.
Never persist a workbook with `pandas.to_excel()` — it drops existing formulas and named ranges.

## Workflow

1. **Explore before coding.** List the sheets, locate the header row, and take the real extent from `ws.max_row` / `ws.max_column` instead of trusting the preview. Read the rows that hold criteria, control values, and reference/lookup tables.
2. **Load twice when formulas are present.** `wb = openpyxl.load_workbook(INPUT_PATH)` is the structure you write back; `wbv = openpyxl.load_workbook(INPUT_PATH, data_only=True)` exposes the cached values behind formula cells. Criteria cells, headers, and source columns are often formulas, so the plain load yields `"=..."` strings while only the value load yields the number you need. Read from `wbv`, write into `wb`.
3. **Anchor on the workbook, not on guesses.** Derive target rows and columns from header or label cells you actually read; never hardcode column letters, row counts, or a summary table's orientation. If the target range already holds rows or formulas, read them first — existing sample rows show the required order and granularity, and a matrix's orientation is settled by its header row and row-label column, not by statistical scoring. For a lookup or mirrored grid, take the target's own row-label column and header row as the keys and fill each cell from the matching pair; when the instruction names which table is the source and which is the destination, follow that direction instead of scoring which block looks richer.
4. **Compute in Python, then write.** Build the result as an intermediate dict/list keyed by the grouping columns, cross-check at least one aggregate against the source data (e.g. the per-category totals should sum to the source column's sum), then write each cell explicitly with `ws.cell(row=r, column=c).value = result`. Cover every row the instruction spans — down to the last populated row or the stated range end: a per-row guard (no residual, no amount parsed) silently leaves the tail of the target range unwritten.
5. **Verify what a value-only reader will see.** After `wb.save(OUTPUT_PATH)`, reload with `data_only=True` and read the target cells back; a formula written by openpyxl has no cached result and reads as `None`.
6. **Re-read the instruction as a checklist.** Enumerate every clause — sort direction, de-duplication, blanks kept blank, formatting, which rows to remove — and confirm each one is implemented; a silently dropped sort or filter clause makes an entire output column wrong.

## Code Patterns

Dual load — cached values for reading, plain load for writing:
```python
wb  = openpyxl.load_workbook(INPUT_PATH)
wbv = openpyxl.load_workbook(INPUT_PATH, data_only=True)
```

Header-driven column map, so no column letters are hardcoded:
```python
cols = {str(c.value).strip().lower(): c.column for c in ws[header_row] if c.value is not None}
```

Look up keys exact-first, with the normalized form only as a fallback, keeping distinct raw keys distinct:
```python
lookup.setdefault(str(raw).strip(), value)   # exact key wins
lookup.setdefault(normalize(raw), value)     # normalized fallback only
```
Prevents strict equality from missing every row and prevents one aggressive normalization from merging two different keys into a single wrong answer.

Write the computed result as a literal value unless a live formula is requested:
```python
ws.cell(row=r, column=cols["total"]).value = total
```

Read back what a value-only reader will see:
```python
openpyxl.load_workbook(OUTPUT_PATH, data_only=True)[ws.title].cell(row=r, column=c).value
```

Remove rows bottom-up so the indices still to be visited stay valid:
```python
for r in range(ws.max_row, first_data_row - 1, -1):
    if should_delete(r): ws.delete_rows(r, 1)
```

## Error Avoidance

- Never rely on `data_only=True` alone: when the file has never been recalculated, every formula cell reads `None`.
- `ws.cell(...).value = "=SUM(...)"` stores a formula with no cached result and reads as `None`; write the computed literal unless the result must recalculate as its inputs change.
- Recover a repaired formula's intent from its existing formula text and neighbouring labels; heuristics flip a table's orientation, which its header row and row-label column settle.
- Keep computed zeros as `0`; apply display placeholders (hyphen, dash, blank) only to results that are genuinely empty.
- "Delete the rows" means `ws.delete_rows(...)` from the bottom up; setting those cells to `None` keeps the rows in place and shifts nothing.
