# 重跑后的独立评价与比较

沿用上一轮冻结的语义评价标准，先分别保存 [A 独立评价](evaluations/A_independent.json)、[B 独立评价](evaluations/B_independent.json)，再形成此比较。由同一分析者完成，不声称双盲。

两组均 HTTP 200，但 finish_reason=length、最终 content 为空，没有实际修改可作语义评价。reasoning token 数不是正式 Update，也不从内部推理补造模型最终答案。

| 评价维度 | A：自由替换 | B：Patch |
|---|---|---|
| 传输有效性 | 成功，1 次 HTTP，无重试 | 成功，1 次 HTTP，无重试 |
| 输出完整性 | completion 预算耗尽，空最终内容 | completion 预算耗尽，空最终内容 |
| 调整/编译有效性 | 未进入解析编译 | 未进入 Patch 应用/编译 |
| 更新对象准确性 | 无实际更新，不可评价 | 无实际 Patch，不可评价 |
| 历史响应利用 | 请求含冻结历史；决定中的使用不可观察 | 同左 |
| 条件和强度 | 不可评价 | 不可评价 |
| 新增无据附带承诺 | 未知，不能记零 | 未知，不能记零 |
| 必要行为保留 | 不可评价 | 不可评价 |
| 具体可执行探索 | 不可评价 | 不可评价 |
| 实际行为收益 | 未执行 | 未执行 |

每份独立评价均记录六个原定语义栏目；缺少输出时为“不可观察/不可评价”，不因技术失败把 Original 的旧问题记为模型未修正，也不以没有生成新承诺而判更好。

**更新粒度：** 唯一真实多行 Original 已存在，但本轮没有实际更新，不能确认 B 比 A 更准确。

**历史参与：** 相同 Memory 确实发出且服务端有正常 HTTP 返回，但仍没有最终决定，无法确认历史如何改变方向、范围或关联。

**策略质量：** 无 Effective A/B，无法判断质量改善、探索保留或方法优越性。两组相同的预算耗尽不是策略等效证据。

本次验证的是更长的连接/发送超时能让冻结的大请求获得 HTTP 响应；这解决了一个实验执行障碍，没有回答预条件化研究问题。
