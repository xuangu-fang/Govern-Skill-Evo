## 3. B：预条件化与统一 Update 作用链

先说明 R1 程序恒等和实际 Memory 形成，再分析 R2。对重要决定沿原始 Update → 历史实际编辑／条件化响应 → Fusion → 有效 Update → Editor diff → 机会／行动／结果 → Memory 修订写证据段落。

- 同时报告有依据的历史驱动变换、历史支持的 Keep、当前证据／能力修正、有界探索及无法判断情况；决定类型与依据来源可重叠，不强制固定标签。
- 历史条件可比性、重要差异、当前 Parent 依赖，以及共同决策组如何参与。
- 方向、尺度（包括扩大）、义务强度、依赖和有效例外的落实／漂移。
- 有行为机会但未执行、未遇到机会、路径变化、已执行后的响应；任务成功不证明具体编辑有效。
- 新 Effect 的联合归因、残余未测范围、允许的扩大／推翻与来源身份；来源正确不等于认识正确。

不要求逐编辑独立因果收益；不以提及 Memory、Effect 引用量或非恒等比例代替实际作用。没有历史新增依据时诚实说明。

## 5. 结论分层

明确区分：程序／来源检查；实际模型语义表现；环境中的行为与任务结果；未验证解释。回答本批次是否持续产生有价值 Candidate、历史是否实质参与 D/S/C、Editor／学习是否保持同一 Update、主要不确定性是什么。
