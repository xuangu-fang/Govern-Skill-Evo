# Question Answering Skill

## Answer Form
- For a work title with a main title and a colon-delimited subtitle, return the main title when the clue identifies the work by its recognizable title and does not ask for the full or formal title. Treat a descriptive subtitle like a translated or alternate title: optional context, not an automatic part of the requested answer. For example, when the clue asks for the book about Texas football and the context gives 'Friday Night Lights: A Town, a Team, and a Dream', return 'Friday Night Lights'. Keep the subtitle only when the clue explicitly asks for the full title, when it is needed to distinguish this work from another, or when the shorter form is ambiguous. Preserve integral articles and established non-subtitle components of a title.
- For reordered or scrambled familiar phrases, when the clue's words appear in an unusual, reversed, or scrambled order and can be rearranged into a familiar proverb, phrase, title, or name, treat the clue as a phrase-reconstruction cue unless it explicitly asks for an origin, author, speaker, or other associated person. Return the corrected familiar phrase or title itself in the `<answer>` element; do not return a person, author, or originator merely because a substantive passage discusses the phrase's origin, and do not return both the corrected phrase and a person or add an explanation or alternatives. This extends the existing spoonerism rule, which still returns the corrected or intended phrase when the clue asks what was said or intended. Preserve existing behavior for ordinary tagline-plus-date clues, fill-in-the-blank clues, and attributed quotations: those still resolve to the work, missing term, or creator as their wording requests.
- For possessive relation clues, separate a request for a relation label from a definite description of a named person. When the clue asks for a person through a possessive phrase such as 'this wife of his' and a substantive passage names that person (for example, Penelope), return the person's name, not the relation phrase 'his wife' or another description. Include the possessive determiner with the relation in the `<answer>` element only when the clue actually asks what relation the person is and the relation itself is the requested answer, for example 'his mother' rather than the bare relation 'mother'. Use the possessive relation as the answer only when the clue or passage ties that relation possessively and no named person is requested. Do not append the named person's name to a relation-label answer when a relation label truly is requested; do not append a role or another qualifier or return multiple alternatives. Preserve full personal names, honorifics, and possessive-marked established phrases such as 'finder's fee' in their proper form.
- For a geographic-feature clue whose distinguishing relation is that the feature shares its name with a country, state, or city, when the clue asks for the feature through that shared-name relation, return the shared proper name itself (for example, 'Kenya') rather than prefixing the feature type ('Mount Kenya'), unless the clue explicitly requests the full feature name or the bare shared name would be ambiguous. This is a surface-form and granularity rule only: keep the selected feature/country relation and do not answer with an unrelated nearby place. Do not generalize it to ordinary feature questions where the clue supplies a feature type and the established full name includes that type; for example, a clue asking about a sea that a hotel overlooks should retain 'Mediterranean Sea' when that is the established name and reference form. Preserve the requested entity-type and containing-entity rules.
- For quoted or bare cues, first classify the cue before choosing an associated label. Apply this classification before the general bare-title association rules below:
  - A visibly truncated title—an ellipsis, a title fragment, or a date attached to an incomplete title—is a title-completion cue: when the clue frames the fragment as missing material, for example by supplying an ellipsis or asking what precedes, follows, or completes it, return only the missing title component supported by the context. Return the full established title only when the clue asks for the work as a whole. Do not return the author or creator merely because the incomplete title is attributed to that creator or accompanied by a date.
  - A complete title or title-plus-date clue is not a truncated-title cue; continue to apply the existing bare-title association behavior, which may resolve to the associated creator or source when the context supports that association.
  - A bare political slogan or campaign phrase should resolve through a substantive passage that explains it as a slogan: return the principal historical figure or candidate that passage pairs with the phrase, not a later song, cover, band, or performer that reuses the phrase. When the slogan names a political ticket, use the passage's explanatory relation to distinguish the principal figure from the running mate, and do not return both.
  - A bare catchphrase or tagline still maps to the associated person or product when the context directly supplies that association. A substantive quotation attributed to a creator still maps to the creator only when the clue is not a truncated title, slogan, or other non-attribution cue. Explicit requests for a song or work title continue to return that title. Keep the answer to one entity and do not add a category or explanation.
- For a named place, landmark, or institution with multiple established aliases in the context, first locate the passage that directly states the clue's defining relation and use the alias that passage attaches to that relation. Do not default to a local-language, original, or current branded form merely because it appears in a heading or a later page.
  - When the clue uses an English descriptive category and the context gives both an English conventional name and a local-language name, use the English conventional name unless the clue asks for the local-language form or the English form would be ambiguous.
  - When the entity has a historical or common name and also a later sponsor or rebranded name, and the clue uses historical features or gives no current-brand cue, prefer the historical or common alias paired with those features rather than the current branding.
  - If no direct relation distinguishes the aliases, select one established form and keep it without appending alternatives. This changes only alias selection, not entity selection or answer completeness; retain full titles, honorifics, and requested formal names.
- When the whole question is only a list of two or more work titles or names and has no explicit question or requested head noun, treat it as a shared-association or category clue. Use a substantive passage that groups those items and return the broad shared topic or historical label that the grouping supplies; do not append an invented genre or format noun such as 'memoirs' or 'novels' when the clue did not ask for form and the passage's answer-bearing label is the broader topic. Keep a format or genre word only when it is part of the established category label requested or needed to distinguish the referent, and do not replace the shared label with a descriptive explanation.

- Before applying the surface-form rules, check the candidate when a clue has multiple identifying conditions, such as an office or role, a place or nationality, a date, and a quoted statement attributed to the answer. First identify the requested answer type, then select the candidate whom the supplied passage or passages jointly satisfy all answer-defining conditions. Do not choose a candidate merely because a distinctive phrase from the clue appears near that candidate's name, or because the candidate shares only one attribute such as state or party. When several people share a state or party, use the remaining relation to disambiguate: which one held the named post, which one the passage directly describes by the statement, and which one it identifies as the subject of the clue. Treat a quotation as evidence only when the context attaches it to that same candidate. Preserve the established name form when the clue asks for the person; this check changes which person is selected, not the answer-boundary rules.
- For historical policy-enforcement clues under the multi-condition check above, when the clue asks which cabinet department, office, or agency was responsible for enforcing a named policy, first locate the substantive passage that directly pairs that policy with the entity for the relevant period. Do not let a generic description of a department's broader law-enforcement role, or a statement that responsibility later transferred elsewhere, override a department repeatedly and specifically tied to the policy unless the clue supplies a later-date or post-transfer cue. Return the requested cabinet-level department rather than a subordinate bureau when the clue asks for the department, and prefer the name form used in the policy-specific relation. If the clue explicitly asks about the later period or the transferred authority, answer the entity tied to that stated period instead. Preserve the requested entity type and do not select by mere proximity to a distinctive phrase.
- For clue-supplied-category answer forms, trailing institutional and corporate descriptors are treated like a category word or legal suffix that merely restates the clue. When the clue itself says what kind of entity is requested, such as a university, college, company, network, or city, and a substantive passage gives both a distinctive short name for that same entity and a longer form containing only trailing institutional or corporate descriptors, return the distinctive short name in the `<answer>` element and do not append those descriptors merely because they occur in the full official name. Treat trailing institution words and attached non-distinctive corporate or industry words and legal endings as the kind of category or form descriptor the answer-form rule already tells the Actor not to repeat. Keep the fuller formal name when the clue explicitly requests the legal or formal name, when the context supports only that fuller form, or when the shorter form is ambiguous or names a different entity. This changes answer granularity and surface form only: preserve full personal names, standard honorifics, established work titles and their integral articles, and any distinguishing qualifier needed to identify the requested referent.
- In the `<answer>` element, return only the entity requested by the clue, not an explanation, a list of alternatives or synonymous names, or an appended parenthetical expansion. When the supporting passage presents a role or thing as 'X or Y' or gives several synonymous names for the same referent, select one term for the `<answer>` element; never return both joined by 'or', a slash, comma, or parentheses. Prefer the term that the question's wording most directly asks for, and if the passage presents the alternatives as equal, use one term consistently rather than listing both; when one is presented as the usual or primary label, use that one. When a passage identifies a work with both an original/main title and a translated/alternate title, return one form only; do not concatenate them with a colon, slash, comma, parentheses, or similar separator. Prefer the main/original title or the form the clue points to, and add the translated subtitle only when the clue explicitly asks for the translation or full title, or the work cannot be identified without it. When the clue asks for a nickname or epithet and has already supplied the general category, return the distinctive nickname itself rather than appending a generic category noun from a fuller passage phrase; retain the fuller form only when it is the standard name and the shorter form would be ambiguous. Keep a title, subtitle, category word, or modifier that is an integral part of the selected single answer or the established title or name requested by the clue, but do not append another synonym or a generic category noun. When the clue itself supplies the category, such as a company, network, or city, return the distinctive proper name or acronym alone; do not add the clue's category word or a legal or organizational suffix that merely restates it, such as `& Company`, `Inc.`, or a trailing `Network`, unless the clue explicitly asks for the full legal or formal name, or the shorter form would name a different or ambiguous entity. These rules protect integral identifying components, full personal names, standard honorifics or titles that are the requested answer, and established work titles with integral articles; they do not require a redundant category or legal suffix. Preserve a valid full title when the extra word is part of the established title or is needed for disambiguation. After the person is selected, choose one standard name form without mixing variants; this changes only the name form, not which person is selected. For middle initials or middle names, use the common first-last form unless the clue explicitly asks for the fuller or formal name, or the context consistently and exclusively identifies the person by the fuller form; do not add a middle initial merely because it appears in some passages. For standard honorifics or knighthood titles such as 'Sir', treat the honorific as part of the established answer label and retain it when a supplied passage directly presents the person with that honorific or formal title in a definitional, answer-like, or repeated identification, even if other passages use a shorter name; a direct answer statement that pairs the title with the name is sufficient, and the title need not appear in multiple passages. This is a specific exception to the general rule against adding a nearby qualifier merely because it appears. Do not drop the honorific merely because a shorter name also appears. Continue to reject an honorific or title that is merely an incidental nearby qualifier, and use the shorter standard name when the context does not directly identify the person by the titled form or when the clue asks for the bare personal name. Choosing the titled form does not change which person is selected and does not authorize adding a role, nationality, or other descriptive qualifier. Preserve genuine full names, requested titles, and unambiguous first-last names. Do not add an acronym expansion, actor/performer name, redundant family-name or dynasty label, role or office label, middle initial, or other nearby qualifier merely because it appears in the passage; include a qualifier only when it is needed to distinguish that specific referent or when the question explicitly asks for the fuller form.
- As a refinement of the personal-name form rules above, when the clue identifies a person only through a role, epithet, description, or quotation, and a substantive answer-like passage itself gives a bare surname or short established name as the answer, use that answer-bearing form rather than expanding to first and last name merely because another passage or page heading uses the fuller form. This exception controls over the general first-last default above when its conditions apply. Do not strip a full name when the direct answer-like passage identifies the person by the full name, when the clue asks for the full or formal name, or when the surname alone is ambiguous or shared. Keep honorifics and other name components when they are part of the direct answer-bearing label under the existing rules. This changes only the selected name's surface form, not which person is selected.
- Apply the same nonrepetition principle when the clue already supplies the requested category or the person's identity: return the smallest sufficient differentiating label supported by the passage rather than repeating that category or identity inside the `<answer>` element. If the clue supplies a geographic feature type and the context presents both a short established regional name and a longer generic-feature form, the short form can be sufficient; do not mechanically append the generic feature noun. If the clue already names the person and asks for a nickname, moniker, or epithet, return the distinctive epithet alone rather than appending the person's surname or full name merely because the fuller phrase appears in the context. Keep a category or type word when it is integral to the established name and the bare head term would be ambiguous or would name a different entity, such as a standard scale or title whose full established label includes that word; keep full personal names and distinguishing modifiers when the clue has not supplied the identity or category, or when dropping them would create ambiguity. This rule governs the final answer element only and does not authorize explanations, alternatives, or synonyms.
- Match the answer to the entity type the clue asks for by first identifying the requested entity from the clue's head noun and prepositions, then choosing the surface form: if the clue asks for a group, character, title, or acronym, return that entity's established name rather than a related person or an expanded description. When the clue asks for a containing site, state, island, forest, or other category ('this site/state/island', 'these'), return that containing entity, not a named building, narrower subdivision, or member mentioned in the same passage. If the requested head noun is the building, subpart, or member itself, return that requested entity instead. For plural class clues, return the class term that covers the listed members and omit an extra subtype adjective that narrows the class unless the clue or context needs that modifier to distinguish the referent.
- When a clue asks for 'the term' or identifies a class in the singular ('this is the term for ...') and the context contains both singular and plural forms, return the singular headword or dictionary form unless the entity's established name is ordinarily plural or the clue asks for multiple distinct instances. Do not copy a plural list form merely because the supporting passage uses it. When a clue asks for a named phenomenon, substance, concept, or other class term and uses a plural frame such as 'these [items]', do not change the term's grammatical number merely to echo that frame. Use the form in which the passage presents the term as the name or headword, often singular, unless the clue explicitly asks for multiple distinct instances or the passage's answer-bearing label is itself a plural common-noun label for a group. Keep established plural names or plural class labels when they are the answer-bearing form. This rule prevents unnecessary pluralization; it does not override ordinary plural answers when the source's direct answer is plural.
- For bare association clues, first decide what the quoted material is being asked to supply. If a quotation is truncated and the clue asks what follows or completes it, return the missing quoted word or phrase supported by a substantive passage, not the work title, author, or a nearby named subject. If the clue presents a deliberate speech error or wordplay such as a spoonerism and asks what the speaker said, intended, or 'talked of,' return the corrected or intended phrase supported by the context, not a person or object referred to inside that phrase; do not return both the phrase and the person. When the entire question is only one or more proper names or bare titles, or place names introduced by a preposition, and contains no description, verb, date, or explicit question, return the context-supported associated label rather than a descriptive fact. A bare quotation or snippet from a literary work, with no speaker label, no explicit question, and no completion or transformation request, is treated as an association clue: when the context attributes it to a named author or creator while also naming the work, return the author or creator rather than the work title merely because the title appears in passage headings. Return the work or title only when the clue explicitly asks for the work or title, or when no author or creator association is supported. When the cue instead names a character or speaker followed by a colon and a quoted line, and a substantive passage identifies that line as coming from a named literary work, treat the cue as asking for the containing work and return the work title; do not return the author or creator merely because headings or context also name the author. If the clue explicitly asks for the author or creator, return that creator. When the clue is a complete bare song, number, chapter, or similar component title, but is not a truncated title, a quotation or line attributed to a person, or an explicit request for the creator, performer, or full work title, and a substantive passage explicitly identifies it as a song, number, chapter, or similar part of a named larger work, treat that containing work as the associated source and return the containing work rather than its composer, lyricist, author, or performer. If no containing work is explicitly supplied, use the existing title/creator association rules for the component title. Return one entity only and do not combine the component title with the containing work or creator. Outside this component-work rule, the existing bare-title association behavior still applies: a bare title or title-plus-date clue may resolve to the associated creator when the context supports that association, and the existing rules for choosing an associated creator or title still apply to truly bare clues. Keep the answer to one entity; do not return both author and title or add an explanation. Personal names or titles of rulers or officeholders still map to the associated country or place, not to a role phrase such as a title plus country or a class label naming the rulers; use the place association only when the clue itself supplies no other requested relation. A single bare place name maps to its containing country or region rather than to a superlative or descriptive phrase about the place. Two or more place names introduced by 'In' map to their shared language, nationality, or demonym rather than to the containing country. A bare list of fictional character names maps to the containing work or series. If the clue supplies a description, date, or other requested relation rather than only a bare quotation, answer that requested entity normally. If no association is supported, return the established proper name rather than inventing a role or relation.
- Apply an explicit specificity test to the answer form. Determine the head category and granularity that the clue requests. If the clue asks for a broad class, such as 'one of these' or 'this category', or gives a foreign-language common noun and asks what it is, return the ordinary class term or standard translation that answers that clue. When a clue uses an indefinite category noun plus a function, location, or property to define a term, identify the class, implement, or type that the clue defines, and return that general label when a substantive passage supports it. Do not substitute a particular example ingredient, brand, or unrequested regional or code subtype merely because a passage mentions it and it shares one property with the clue. Use a specific member or subtype when the clue explicitly asks for that member or subtype, when the clue already supplies the category and requests a distinctive proper name, or when the bare class label would be ambiguous in the supplied context. This changes the level of description, not the selected referent when a specific answer is genuinely requested. Do not add a narrower subtype adjective, a national or heraldic epithet, or another descriptive modifier merely because a passage uses it. Add such a modifier only when the clue explicitly asks for that subtype or epithet, when the modifier is needed to distinguish the referent from another entity, or when it is an integral part of the established name requested. Preserve genuinely complete answers such as full personal names, established titles and honorifics, established work titles with integral articles, and distinguishing variety or species labels when dropping them would change the named entity.
- For unanswered question-archive passages and superlative clues: if a supplied passage merely repeats the question or presents a crossword or Jeopardy clue without its answer, do not treat words near that repetition or the archive page title as evidence for the answer; use a substantive passage that states the requested relation. For a superlative or comparative clue such as 'this war ... greater than all other wars' or 'the largest ...', identify the entity that a substantive passage places in the superlative role, rather than a related entity merely discussed nearby or a more familiar alternative. If the substantive passage states a closely related measure rather than the exact wording, use it only when it is the clearest supplied comparative statement and does not contradict the requested relation. If no supplied passage supports the comparison, use the best-supported candidate without letting the unanswered archive line override a substantive passage. Preserve the requested entity type and the answer-boundary rules.
- As a narrow exception to the one-selected-term rule above, when the clue itself sets out two distinct definitions or wordplay senses, often separated by a slash, and a direct answer-like passage presents the answer as a paired homophone or paired word form, return that pair as a single answer unit in the passage's shown order and notation rather than collapsing to one member. This exception applies only when both parts are needed to answer the paired clue. Ordinary synonyms, translated or alternate titles, 'X or Y' phrasing, and lists of possible entities remain subject to the one-selected-term rule; if the context does not supply a paired direct answer, return one word. Do not use this exception to add an extra category or explanation.
- For completion-style clues, first identify the slot the clue itself has created before choosing the surface form. When the clue supplies part of a word, title, or phrase and asks for the missing material, such as a prefix followed by 'this' or a relational frame such as 'rate of this', return only the value that fills that slot, not a fuller compound or a phrase that repeats a supplied term. When the clue asks for a base class through a frame such as 'they have some called ...' with examples from more than one place, return the class term and do not append an extra subtype adjective that merely echoes one example. Preserve the full term when the clue explicitly asks for the whole word or term, when the slot cannot be separated without changing the entity, or when the requested entity is a category-bearing name whose omission would be ambiguous. Retain established titles and necessary qualifiers; this refines, rather than replaces, the shortest-sufficient and plural-class rules above.
- For a role or office supplied as 'this ... officer' or a similar category-and-role clue, prefer the title form used in the substantive sentence that states the clue's defining relation over a country-qualified heading form. Do not add a prefix such as 'United States' merely because it appears in a page or section title. This is only a surface-form and alias choice: select the same entity, and preserve integral title components, articles belonging to an established work or property name, standard honorifics, and any qualifier needed for disambiguation. If the context supports only the full formal name, or the clue explicitly requests it, keep that full form.
- These restrictions apply to the final answer element only; ordinary step-by-step reasoning outside that element can still be used.
