# Question Answering Skill

- Answer with the concise entity or term that fills the clue's slot; do not substitute or supplement a performer or portrayer when the clue requests a character or title entity. Omit role labels, parenthetical glosses, synonyms, and category words already supplied by the clue. When the supporting sentence gives the requested term directly, return that term alone, since a correct term plus extra material can still miss the requested answer.
- When a plural clue asks for the general source (for example, 'these animals') and passages identify a particularly or characteristically preferred source alongside other possible or occasional sources, answer that preferred source alone instead of listing every alternative. Enumerate multiple sources only when the clue explicitly asks for all possible sources.
- Treat a fragmentary question as a fill-in-the-blank. Use the passages to identify the missing word or entity: complete a leading-ellipsis quotation with the proper noun that makes the known phrase, and expand a trailing place code or abbreviation to the place name. Do not instead return a prominent song, work or artist, or a landmark associated with the visible words, unless the question explicitly asks for that item.
- When the question is only a bare proper name or a list of names or identifiers, return the associated title or named entity, not a descriptive role/group label or a longer variant of the clue. Strip a title or role word shared by all listed names and return the place or collective that completes it; for a single place name, return its containing state/country when the passages repeatedly state that relation. Do not apply this to cryptic clues with an explicit word-length/wordplay cue, or when the clue itself asks for the role or group.
- When the clue asks for a general item ('this … fish', 'one of these', 'this … material') and a passage defines the requested slot with a base noun, return that base noun alone; do not upgrade it to a named subtype or add a modifier the clue does not request. Keep a specific subtype only when the clue itself names it or explicitly asks for the subtype or variety.
- For a person answer, use the name form in the passage sentence that states the clue's identifying fact. If that sentence gives only a surname, return the surname alone; if it gives a formal full name, do not substitute a nickname from a heading or another passage. Do not expand a surname to a fuller name found elsewhere unless the clue itself requires that fuller form.
- For a title answer, start from the passage phrase that states the clue's fact, but do not copy a descriptive or award-category suffix that the clue already supplies as the category. Drop a generic category word the clue uses for the type (for example, 'party' or 'network') and return the distinctive title without that same word; keep the full title when the word is an integral part of the title rather than a category supplied by the clue. If the clue instead asks for a publication and uses only a broader synonym for the type (for example, 'journal'), keep the publication word that the passage gives as part of the title (for example, 'magazine'). Do not extend a film's subtitle when the title's shorter form identifies the film.
