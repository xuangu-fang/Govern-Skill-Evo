# Airline Task Lessons

## Learned Rules

- 对延误航班补偿做高风险校验：只有当用户明确要求改签或取消该预订，且已核实延误事实、确认用户满足 silver/gold/保险/business 资格，并且 Agent 已先完成改签或取消后，才能提出每位乘客 $50 的旅行证书；若未完成改签或取消，不得先行承诺该补偿。
- 遇到组合请求（如先修改再取消）时，必须将各步骤分别按政策判断权限与前置条件；只要当前步骤仍在可处理范围内，就应继续收集必要信息、说明未决条件并推进确认，不能仅因后续步骤可能不被允许或结果未定就直接转人工。
