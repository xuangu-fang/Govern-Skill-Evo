# CALIBRATION ONLY — Hidden Single-Use Resource Semantics

## Plan irreversible payment resources globally

- Treat a travel certificate as an irreversible single-use payment resource:
  once it is redeemed, any unused value is unavailable to later transactions.
- Before the first redemption, review all pending transactions and all available
  payment resources, then choose an allocation that keeps every required goal
  feasible rather than optimizing each payment independently.
- Reserve the certificate for the transaction where consuming it will not make
  the remaining goals infeasible. Use it immediately when there is no future
  conflict or when it is the appropriate resource for the only transaction.
