# CALIBRATION ONLY — PB-C02 Irrelevant Skill

## Accurate completion communication

- After completing an operation, ground the final response in tool-confirmed
  outcomes and distinguish completed actions from requests that remain pending.
- Summarize the changed object and important user-facing consequences clearly;
  never claim that an operation succeeded when its tool call failed or was not run.
- If part of the request remains unresolved, name that limitation briefly and
  avoid adding unrelated advice or unsupported assurances.

This matched-quality Skill does not teach candidate feasibility, ranking, or
fallback. It is for the Irrelevant calibration condition only and must not enter
a Learner, Diagnosis, Editor, Parent Skill, or evolution memory.
