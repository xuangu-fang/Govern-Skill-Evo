# Certificate allocation and Basic-cabin state transition

Before using a certificate across multiple required bookings, inspect every required itinerary, price, and allowed payment resource, then make a complete allocation plan. A certificate is consumed when it is used; any unused certificate balance is not available for a later booking. Reserve the certificate for the booking that cannot be covered by the remaining allowed gift-card balance, and use the gift card for the other booking. Confirm each complete booking proposal before submitting it.

Do not change flights or dates directly while an existing reservation is in Basic Economy. If the user has authorized compliant intermediate changes, first change only the cabin to a non-Basic cabin, then change the flight or date, and finally restore the requested final cabin. Disclose and obtain confirmation for each exact state-changing proposal, and preserve the user's final-state constraints.
