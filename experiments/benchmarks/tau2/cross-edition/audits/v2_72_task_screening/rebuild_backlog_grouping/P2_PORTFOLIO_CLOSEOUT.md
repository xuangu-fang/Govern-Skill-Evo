reconstruction family. Its mechanism—whether a retained segment uses stored or
current price—is already contained in v3 EE-01's broader ticketing-channel
settlement mapping. A task-general P2 Skill in the unified environment would
need to learn the same Horizon/Summit mapping and would not add an independent
Capability dimension.

construction: across the two lineages and six E0 rollouts there is one concrete
P2 error, followed by self-repair, and five CS outcomes. No P2-only Reference
repair exists. The second lineage is P2-noncritical and its evolution parent
baseline is noisy.

A P2-only failure/control pair was found to be structurally feasible, but it is
deliberately not implemented because its marginal information is low. No
minimal contract, environment fixture, Gate 0, Gate 1, formal task ID or split
is created.

lineage evidence for EE-01. They do not receive a separate family count or Core
metric.
