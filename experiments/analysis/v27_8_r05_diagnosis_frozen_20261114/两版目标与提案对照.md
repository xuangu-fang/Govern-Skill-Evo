Improve accuracy on strongest-statement multiple-choice items by rejecting substantive options that weaken or overstate a supported conclusion when a stronger-result option is available, while retaining a substantive option that already matches every supported clause.

**Reason**

The batch shows a recurring pattern on strongest-statement items: a substantive option that resembles a standard theorem is selected even when the scored target is the meta-option saying a stronger result exists. P1, P5, P6, and P9 each involve a near-miss substantive statement that appears to weaken or omit one clause, such as global versus local smallness, endpoint inclusion or an extra correction term, an additional invariant, or exact degree versus 'at most'. Parent already says to treat a stronger-result option as live when every substantive option is intermediate or overstrong, but the Actor did not systematically reduce candidates to formal clauses. **U1**

When a question asks for the strongest provable statement and one choice says a stronger result can be proven, first write the candidate conclusion as a list of required clauses: exact quantifiers, parameter range and endpoint, global versus local norm, exact versus 'at most' degree, bounded versus epsilon-small, dependence of constants, nonnegative correction terms, and every invariant named in the stem. Test each substantive choice clause by clause. Mark a choice as a near-miss if it drops a supported strengthening, such as 'at most' for an exact degree, a strict subrange for an inclusive range, a local estimate for a global one, a bounded estimate where smallness is available, an extra correction term, or an omitted invariant, or if it adds an unsupported strengthening, such as a uniform constant or a larger parameter range. Do not choose a near-miss merely because it resembles a standard theorem; after identifying the mismatch, use the existing meta-option rule to decide whether the generic stronger-result choice is live. If a substantive option matches all supported clauses, retain it.
