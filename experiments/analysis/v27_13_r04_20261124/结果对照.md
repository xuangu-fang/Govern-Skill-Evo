# v27.13 两组 R04 短回放

两组均完成 Diagnosis、Preconditioner 和 Editor，并通过只读重验。两份候选 Skill 都把“有具体选项成立，但可以证明更强的结果”作为有条件的提交策略。首次组写入了原 Parent 缺少的分支，重复组加重了已有分支的改选条件。回放止于候选文本，尚无候选作答、EM 增损或 Gate 裁决。

## 原始证据

两组来自 v27.11 两次训练的 R04，题序相同，Parent 和 Memory 各自取本次训练当时的归档。10 道题中，P1–P5、P9、P10 有目标选项，七次参考答案均为该项，两个 Parent 七次均提交了具体选项。其余三题各组均答对 P6、P8，答错 P7。两组各为 2/10，其中触发组各为 0/7。它们是同一批七道触发题的两次历史执行。该批没有目标选项出现而具体项正确的反例。

| 对照 | 首次训练的 Parent | 重复训练的 Parent |
| --- | --- | --- |
| 旧指令允许什么 | 要求比较全部选项、关注结论强弱，缺少针对该元选项的提交条件。 | 已要求在出现该项时暂选它，只有具体项能证成恰为最强结论时才改选，包括只问“哪个陈述成立”的题。 |
| 新候选写了什么 | 先把元选项列为认真比较的候选。若所有具体项都有适用域、充分性、刻画等缺陷，或均未陈述题目完整范围内的结果，就提交元选项。具体项精确覆盖全范围、且无额外断言时允许改选。 | 对问最强、完整或等价结论的题，一开始就让元选项领先。要改选具体项，须同时确立该项为最强具体结论、且无法证明更强的相容结论；未决则提交元选项。其他问法沿用原 Parent 分支。 |
| 新规则能覆盖哪些历史遗漏 | 七道均属于相关问法。Diagnosis 的理由称之为“入口默认”，但实际补丁写的是先认真比较、再依据具体项缺陷或完整性选择，两者有区别。 | 加强的分支按题目措辞覆盖七道中的六道。P1 只问哪个陈述成立，仍走历史上已选错的旧分支。新的排除条件可能很难满足，本批无法检验它会错过哪些正确具体项。 |
| 额外提案 | P7 提出从各素数局部等价过渡到整体等价前，检查是否有组装局部等价的依据。 | P7 也生成独立更新，要求检查相容性或拼接论证。 |

两组各产生两条 Original，Preconditioner 四次都给出 KEEP，Editor 均实际写入。首次组下游收到了 P1–P5、P7、P9、P10，重复组收到了全部十题。重复组 Diagnosis 把答案分布解释为 Actor 把“看似合理”当成“精确”，但仅凭标签能确认的只有提交结果，不能恢复其判断过程。[首次组提案](first/diagnosis/attempts/001/parsed.json) · [首次组裁定](first/preconditioner/attempts/002/parsed.json) · [首次组补丁](first/editor/attempts/001/actual.diff) · [重复组提案](repeat/diagnosis/attempts/001/parsed.json) · [重复组裁定](repeat/preconditioner/attempts/001/parsed.json) · [重复组补丁](repeat/editor/attempts/001/actual.diff)

v27.12 的对应回放也为两组写出了目标策略，每组最终只写一条。v27.13 这次在两组都从同一道 P7 写入另一条规则；该操作有具体数学含义，其在其他题上的价值尚无配对结果。仅从本次候选文本看，可以确认目标信号能传到 Editor，尚不能判断哪个版本会多答对题。[v27.12 两组结果](../v27_12_r04_diagnosis_v2_20261118/结果对照.md)

## 执行口径

旧回放的内网端点在本次执行环境无法解析。三个生成模块使用正式配置的 DeepSeek 官方服务 `deepseek-flash`，旧回放生成模型为 `deepseek-v4.1-flash`。提示词按 v27.13 定稿加载，仅将历史 Actor 模型名替换为原始执行使用的模型。两组 Diagnosis 用户消息逐字匹配各自归档。下游输入由本次真实提案编译。模型温度、推理预算、重试及契约沿用冻结设置。模型来源与 prompt 均有差异，跨版本比较限于实际产物。

六个阶段共发出七次模型请求。首次组 Preconditioner 第一次返回的 Memory 引用缺少规定的反引号，依照原协议重试后通过。其余五个阶段首次通过。[运行入口](replay_frozen.py) · [首次组候选 Skill](first/editor/attempts/001/candidate.md) · [重复组候选 Skill](repeat/editor/attempts/001/candidate.md)
