# v21 Evidence Review 的证据比较

日期：2026-10-10。对应真实模型局部对照后的优化第 2 步，接续[退化证据跨轮保留](V21_REGRESSION_RETENTION.md)。

本步解决的是：原始正反证据已经加载，但 Review 的修改依据没有充分回应它们。保留证据与使用证据是两个不同的验收对象。只调整 v21 Review 提示，版本由 `evidence-review-v21.4` 升为 `evidence-review-v21.5`。

## 实现要求

在原有 `reason`、`gap` 和引用字段中完成比较，不增加响应字段或额外调用：

1. 回应对当前问题和修改方向有实质影响的正面历史及反例，包括未标记为 `known_counterevidence` 的相关成功观察。不要求逐事件或逐 edit 列表。
2. 比较实际行为、参数、返回结果及执行时条件；说明用户意图/授权、信息可得性、政策和工具背景中的关键差异或未知。成功与合规标签保留原轨迹归属，跨轮观察不能冒充显式 Replay 配对。
3. 区分实际观察、条件性支持和因果假设。仅列出引用不等于回应证据；相反观察为何限制结论，或者为何不适用于当前情况，应在理由中说明。
4. `VERIFIED` 必须落到当前 Parent 中有证据支持的行为缺陷和可执行、有适用条件的修改。隐藏的完整政策不可见，不自动否定有限经验支持；经验也不能覆盖可见政策或证明某条隐藏规则。不能为了通过单例增加规则，不能将偶然成功泛化。
5. `NO_EDIT` 仍须回应相关正面和负面证据，说明阻碍合理修改的具体缺口或当前覆盖情况。已有文字不证明执行有效；原因尚不明确也不必然排除有依据的有限修改。没有足够行为证据或缺少执行前提时允许不改。

Fusion、Memory 更新、证据选择、无损打包、校验器和 Editor 均保持既有逻辑。2,000 字符 Memory 硬限制不变。不增加独立 Agent、重复 Review、状态分类或自动语义评分。程序校验仍只能验证契约和引用，不能证明比较合理。

## 验收与后续真实验证

受控测试验证原始输入可无损进入 Review，双侧引用、反证和理由保留，`NO_EDIT` 只执行一次 Review、不调用 Editor、不产生候选，保存后可复验。相关回归继续覆盖 `VERIFIED` 经 Compiler/Editor 生成候选及引用/编辑权限约束。构造响应不代表模型已经学会比较。新增 1 项 NO_EDIT 通路测试，连同相关 v21/v20/Replay 回归共 **211 项通过**（58.51 秒）。

后续小规模真实验证应固定本步三组原始输入，仅替换 Review 提示，复用原输出比较，不重跑两批完整消费。判定依据是：是否回应决定性的正反证据；是否按真实条件解释可比性和限制；是否区分观察与推测；是否对当前 Parent 给出有依据的修改或具体的 `NO_EDIT` 理由。不得以 `VERIFIED` 数量或是否修复当前案例作为唯一标准。三个案例没有强制预期 verdict。

本步没有真实模型调用、Replay 或活动 Skill/Memory 发布。真实模型是否改善，留待计划中的分阶段验证。
