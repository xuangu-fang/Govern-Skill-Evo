# v27.18 · 从成功与失败的作答中发现共同决策

[Diagnosis](prompts/diagnosis.md) 从一次错答出发，在整批记录里找面临同一决策的其他题，包括答对的题。分组依据是 Actor 在作答前能看到什么、需要决定什么。不同数学主题可以共享一个决策。

在同一组里比较实际提交与参考答案，同时检查支持解释的样例和反例。结合当前 Parent，提出一个可以在新题上执行的动作，并说明这个动作怎样修正错答、保留正确作答。作答标签能表明 Actor 选了哪一项，具体的推理过程仍属推测。

把 Update 正文逐字应用回引用的失败与成功样例。若照做后仍可能犯原来的错误，在 `reason` 中说明尚未解决的部分。若一个限定或中间检查会改变动作，就解释它的依据。影响适用范围的记录随 `basis` 转发。
