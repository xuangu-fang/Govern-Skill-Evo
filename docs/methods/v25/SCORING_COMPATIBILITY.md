# SpreadsheetBench 评分兼容修复

2026-10-27：保留 SkillAdam 的保存值比较规则，仅补齐区域解析兼容性，并把逐题 `per_cell_pass_rate` 四舍五入到 4 位小数。主指标 `hard` 仍要求评分区域所有单元格正确。V25 与 SkillAdam 接入层共用这份评分实现。

## 修复范围

| 题目 | 新配置/解析行为 |
| --- | --- |
| test:60-7 | 精确匹配已知元数据组合，将四个工作表名称拼接的字段解析为目标表 `Consolidated Tracker`，评分区域 `A3:E11`。修正记录写入新配置 `dataset.scoring_compatibility.metadata_corrections`。 |
| test:283-32 | 支持 `A:G` 整列范围，从第 1 行比较到标准答案与预测文件两者的最大行数，避免漏掉预测文件的额外行。 |
| test:73-45 | `BD2:308` 继承起始列，按 `BD2:BD308` 比较 307 个单元格，不允许空范围自动成功。 |
| test:130-9 | 保留已有的含逗号表名解析支持，`b2b, sez, de` 是一个工作表名称。 |

前三题是旧配置中暂缓的三题。第四题此前在 V25 已可正常评分，本次仅保留并回归验证。整列和省略结束列的修复是语法规则，不按题目硬编码分数。反向范围和非法范围继续报错。

原始数据、标准答案、任务文字与划分清单不改。`60-7` 的区域元数据会进入 Actor 初始消息，因此新配置也会向 Actor 展示解析后的正确目标表；各方法须统一使用新配置。其余 399 题的任务配置保持不变。

不增加字体、颜色或其他样式评分，不执行公式重算。评分仍读取 `data_only=True` 的保存值；缺少公式缓存仍可能判错。`73-45` 的原始输入在修正范围后仍可通过值比较，这属于值评分无法识别部分格式操作的限制，不以本次解析修复改变它。

## 离线验证

- 全部 400 题标准答案对自身评分：80 Train、40 Val、280 Test 全部通过，比较区域非空。
- 原先可评分的 397 题：用原始输入工作簿对标准答案评分，与上一轮 campaign 冻结的评分源码逐题比较，`hard`、正确/总单元格数、错误坐标、缺失工作表均一致；辅助正确率仅增加四位小数舍入。
- 专项覆盖整列额外预测行、缺失工作表、307 单元格边界、非法范围、完整 280 题顺序和配置冻结校验。
- V25 测试集 254 项通过；无模型请求，无生成程序执行。

自检证明这些数据可被解析、标准答案可通过以及既有判定回归稳定，不代表对所有可能预测文件或任务语义的完整证明。

离线审计入口为 `scripts/runs/verify_spreadsheetbench_scoring_compat.py`，读取指定旧 campaign 的冻结评分源码进行比较。报告为 `experiments/evaluations/spreadsheetbench_full280_skilladam_compat_actor48k_20261027_001/scoring_audit.json`。
