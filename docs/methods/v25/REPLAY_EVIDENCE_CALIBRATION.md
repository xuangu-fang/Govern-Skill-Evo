# Replay v2：事实比较、经验范围与待验证假设

本页保留 v2 实施记录；后续默认已更新为 [Replay v3](REPLAY_CONDITIONAL_COMPARISON.md)，旧 v2 正文与归档仍按原版本读取。

2026-10-28，本次实施时 Replay 默认版本为 `v25_replay_evidence_calibrated_v2`。
Preconditioner 继续默认 `v25_preconditioner_evidence_decision_boundaries_v7`。
本次只局部修订 Replay Prompt 及其版本选择、兼容读取和未来配置，不运行模型实验。

## 修改依据

[R05 / R06 传递审计](REPLAY_MEMORY_R05_R06_AUDIT.md)没有发现 active Memory 在存储或
投影时丢失，但发现 Replay 对部分行为和归因概括过强，以及下游独立存在的误读。
旧 Prompt 已要求联合干预、保留不确定性和适当泛化，本次将相关要求具体化并替换
原段落，不另加一套审查阶段，也不把所有问题归咎于 Prompt。

关键案例包括：M9 将评分通过数写成转换格数、将错误坐标写成未改写事件，遗漏
P3/Q3 残差正负号对应的加减方向变化；原始训练 R06 Replay 将相同分数及错误坐标
写成没有评分格改变。M8/M9 的发布前审查也曾纠正角色和 unmatched 分支的描述。
这些案例支持提高比较准确性，不要求禁止尚未隔离因果的修复假设。

## 四处局部替换

| 位置 | 修改 | 解决的问题 |
|---|---|---|
| §1 Observation 与 §3 行为判断 | 区分代码规定、输入或运行记录所能确定的事件、评分结果；代码和已知输入足以确定路径时可直接判断，不强制分支日志 | 防止把条件分支当作已执行事件，把正确格数当写入数，把同分或同错误坐标当相同输出值 |
| §3 实际程序比较与联合干预 | 归因前比较有实质影响的程序差异，包括未由 Skill 明示要求的变化；区别新增行为和双方已有行为，保留重要竞争解释 | 避免只寻找符合修改意图的解释，遗漏符号方向变化，或将原本已有的数值容差作为新增原因 |
| §4 自包含经验、范围与不确定性 | 明确允许观察、解释及有依据的机制假设；按共享任务语义和机制泛化，不设最低案例数；不确定性放在受影响主张上，保留真实收益、退步和未测得收益 | 保留探索和迁移能力，避免宽泛默认获得过度支持，也避免因根因未知而抹掉有效经验 |
| §6 当前主张核对 | 核对比较两侧是否为相同相关条件、数量口径是否正确、事件是否有证据；修正错误前提而不是只在末尾加因果保留语 | 提前发现两侧其实相同的 unmatched 行为、角色混淆及评分数与行为数混用；不要求逐行穷尽追踪 |

## 合并与冲突检查

- 证据含义集中在 §1，§3 的行为判断引用该边界，不重复展开分支与评分规则。
- §3 的笼统“其他解释”检查及联合干预段落改为实际程序比较与有边界的归因。
- §4 合并自包含经验和泛化表述；将“每条 Knowledge 必须为真”改为准确表达事实支持、
  范围以及假设状态，避免与允许未证实假设冲突。反例必须约束相关主张的要求保留。
- §6 负责关键主张的事实对应检查，不重复 §3 的全部归因和 §4 的全部泛化规则。
- §5 的完整 MemoryEntry 替换语义、§7 输出契约及 Current pairing view 原文不变。
  没有新增标签、字段、固定模板、Knowledge 数量限制或最低案例数。
- 历史原始来源仍不进入 Knowledge Only 模型输入，不要求回读不可用的来源。
  有证据支持的假设不必等待独立因果证明；未触发、未测得收益与全局无效继续区分。

正文按空白分词由 2,502 增至 2,707 词，增加 205 词；没有追加独立检查清单或案例专用规则。

## 预期变化，尚未通过模型验证

- R05 文本经验：保留 14/16 → 16/16 的结果及归一化修复假设；不再将其写成全部
  16 格被改写，或在实际值不可见时确定 E10/E11 的失败路径。
- R05 数值经验：保留边界查找／残差传播方向，并记下正负号到加减动作的映射也改变；
  不把某一查找分支或某个单独改动的收益说成已证实。
- R06 标识符经验：记录分数和错误坐标未改善；不由此推断所有输出值完全相同，
  也不将本次未测得收益扩成机制普遍无效。
- 继续保留 M1/M4 等有效正反对照和有依据的机制假设。下游将 M8 读反或扩大范围
  是另一个问题，不宣称只改 Replay 已解决。
