# v27.19 · 判断提案中的哪些内容值得写进 Skill

v27.19 以 v27.18 的 LMB 五轮训练为基线，改动集中在 Preconditioner。它审查 Diagnosis 转发的当前题目、Parent 和相关 Memory，决定一个 Original 应当原样进入 Editor、带着修订进入 Editor，还是撤回。后续比较沿用 v27.18 的 Gate 和训练配置，以便把差异定位到这次 prompt 修改。[Preconditioner 完整提示词](prompts/preconditioner.md)

## 审查依据

先找出实际提交的选项和参考选项在哪一点上有分歧。再逐项检查提案希望 Actor 学到的条件、例外和例子。省去某个细节时，如果一条有证据的规则会选错、丢失必要边界，或变得难以识别，就应保留该细节。若两个选项本来就共享这个细节，把它单独写成指令需要另外的依据。一个训练样例也可能揭示可迁移的区别，关键在于能否从题内信息说明理由。

最后把余下的指导与 Parent 逐项对照。原案中的各部分都有依据且对 Parent 有新增价值时用 `KEEP`。核心动作成立、但混入题目细节或缺乏依据的限制时用 `REPLACE`，把完整有效指导放进 `text`。余下内容已被 Parent 清楚覆盖，或只有知道参考答案才能执行时用 `WITHDRAW`。沿用 `adjustments` 输出契约，证据和不确定性写在 `reason`。

## 两个历史案例如何区分

| 历史训练提案 | 设计预期 | 核对理由 |
|---|---|---|
| R04 的局部等价与 gcd | 原样 `KEEP` 缺乏依据。去掉 gcd 子句，再判断余下内容适合 `REPLACE` 还是 `WITHDRAW`。 | 错选 A 和正确 C 共享同一个 gcd 条件。两者的分歧是普通等价与逐素数的局部等价。若保留局部等价的例子，应说明它如何帮助识别 Parent 原有“警惕过强结论”未说清的判断。 |
| R01 的特定选项措辞 | 保留原文作为触发线索，以及出现该选项时选择其标签的动作。 | 7 道训练题出现这段措辞，参考答案 7 次都是它，Actor 只选中 1 次。删掉措辞会失去判断选项的依据。给规则附加题干类型或其他选项的限制，同样需要在动作发生分歧处给出证据。 |
