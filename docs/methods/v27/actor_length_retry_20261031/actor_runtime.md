The frozen Actor uses deepseek-flash with thinking enabled, reasoning_effort=medium and temperature=1.0. It has one model round, no tools and a per-request output limit of 16,384 tokens, including any provider-accounted reasoning tokens. Request timeout is 300 seconds and connection timeout is 10 seconds. Technical failures and length termination share at most six total request attempts, including the first, with no hidden SDK retries. A length response is archived and retried with identical messages and output budget, even if it contains a parseable answer. Only a stop response is scored. Exhausting all six attempts stops the task without a score; resume never resets this budget. Wrong answers and format noncompliance in a stop response do not trigger corrective generation. These are execution constraints, not new Skill instructions or output fields. Independent reasoning_content is unavailable to the method modules regardless of its token usage.
